Question 1:
Show that a process $(X_t)_{t\in \R^+}$ is a Brownian motion if and only if: $X_0=0$, $(X_t)_{t\in \R^+}$ is a centered Gaussian process, ${\rm Cov}(X_s,X_t)=\inf(s,t).$

Answer:
## Step 1: Recall the definition of Brownian motion
A stochastic process $(X_t)_{t\in \R^+}$ is a Brownian motion if it satisfies the following properties:
- $X_0=0$ almost surely,
- For all $s,t\geq 0$, $\mathbb{E}[X_t]=0$ and ${\rm Cov}(X_s,X_t)=\min(s,t)$.

## Step 2: Show that if $(X_t)_{t\in \R^+}$ is a Brownian motion, then it satisfies the given conditions
If $(X_t)_{t\in \R^+}$ is a Brownian motion, then by definition:
- $X_0=0$ almost surely,
- For all $s,t\geq 0$, $\mathbb{E}[X_t]=0$ and ${\rm Cov}(X_s,X_t)=\min(s,t)$.

## Step 3: Show that if $(X_t)_{t\in \R^+}$ is a centered Gaussian process with covariance function $\inf(s,t)$, then it satisfies the properties of Brownian motion
Since $(X_t)_{t\in \R^+}$ is a centered Gaussian process, for all $s,t\geq 0$, we have:
- $\mathbb{E}[X_t]=0$,
- ${\rm Cov}(X_s,X_t)=\inf(s,t)$.

## Step 4: Show that the process $(X_t)_{t\in \R^+}$ is a Gaussian process
Since for all $s,t,u,v\geq 0$, we have:
$\mathbb{E}[X_t X_u] = {\rm Cov}(X_t,X_u) + \mathbb{E}[X_t]\mathbb{E}[X_u]$
$= \inf(t,u)$,
and
$\mathbb{E}[X_s X_t] = {\rm Cov}(X_s,X_t) + \mathbb{E}[X_s]\mathbb{E}[X_t]$
$= \min(s,t)$.

## Step 5: Show that the process $(X_t)_{t\in \R^+}$ has independent increments
For all $s<t<u$, we have:
$\mathbb{E}[(X_u-X_t)(X_s-X_t)] = {\rm Cov}(X_u,X_s)-{\rm Cov}(X_u,X_t)-{\rm Cov}(X_t,X_s)+{\rm Cov}(X_t,X_t)$
$= \inf(u,s) - \inf(u,t) - \inf(t,s) + t$
$= 0$.

## Step 6: Conclude that the process $(X_t)_{t\in \R^+}$ is a Brownian motion
Since $(X_t)_{t\in \R^+}$ satisfies all the properties of a Brownian motion, we conclude that it is indeed a Brownian motion.

The final answer is: $\boxed{1}$

Question 2:
Show that if $W_t$ is a Brownian motion, $ \{X_t=t\;W_{\frac 1t}, t>0, X_0=0 \}$ is a Brownian motion too.

Answer:
## Step 1: Recall the definition of a Brownian motion
A stochastic process $\{W_t, t \geq 0\}$ is called a Brownian motion if it satisfies the following properties:
- $W_0 = 0$
- The increments are independent, i.e., for any $s < t$, $W_t - W_s$ is independent of $\mathcal{F}_s^W = \sigma(W_u : u \leq s)$.
- For any $t > 0$, $W_t - W_s \sim N(0, t-s)$.

## Step 2: Verify the first property
We have that $X_0 = t\cdot W_{\frac{1}{t}}|_{t=0} = 0$ by definition of $X_t$. Thus, the first property is satisfied.

## Step 3: Verify the second property
Let $s < t$. We need to show that $X_t - X_s$ is independent of $\mathcal{F}_s^X = \sigma(X_u : u \leq s)$. Note that
\begin{align*}
X_t - X_s &= tW_{\frac 1t} - sW_{\frac 1s}\\
&= (t-s)W_{\frac 1t} + s(W_{\frac 1t} - W_{\frac 1s})\\
&= (t-s)W_{\frac 1t} + s \left( W_{\frac 1t} - W_{\frac 1s} \right).
\end{align*}
Since $W_t$ is a Brownian motion, the increments are independent. Therefore,
$$
(t-s)W_{\frac 1t}, \quad s(W_{\frac 1t} - W_{\frac 1s})
$$
are independent. Moreover, since $\mathcal{F}_s^X = \sigma(X_u : u \leq s)$ is generated by the values of $W$ up to time $\frac{s}{t}$ for some $t > s$, we have that $(t-s)W_{\frac 1t}$ and $s(W_{\frac 1t} - W_{\frac 1s})$ are independent of $\mathcal{F}_s^X$. Thus, the second property is satisfied.

## Step 4: Verify the third property
We need to show that for any $t > 0$, $X_t - X_s \sim N(0, t-s)$.
\begin{align*}
\text{Var}(X_t-X_s) &= \text{Var}((t-s)W_{\frac 1t} + s(W_{\frac 1t}-W_{\frac 1s}))\\
&= (t-s)^2\text{Var}(W_{\frac 1t})+s^2\text{Var}(W_{\frac 1t}-W_{\frac 1s})\\
&= (t-s)^2 \cdot \frac 1t + s^2 \left( \frac 1t - \frac 1s \right)\\
&= t-s.
\end{align*}
Since $X_t-X_s$ is normally distributed, we conclude that it is a Brownian motion.

The final answer is: $\boxed{1}$
