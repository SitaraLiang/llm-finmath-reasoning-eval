Question 1:
Show that a process $(X_t)_{t\in \R^+}$ is a Brownian motion if and only if: $X_0=0$, $(X_t)_{t\in \R^+}$ is a centered Gaussian process, ${\rm Cov}(X_s,X_t)=\inf(s,t).$

Answer:
## Step 1: Recall the definition of Brownian motion
A stochastic process $(X_t)_{t\in \R^+}$ is a Brownian motion if it satisfies the following properties:
- $X_0=0$
- For any $s,t\geq 0$, $\mathbb{E}[X_t]=0$ and ${\rm Var}(X_t)=t$
- For any $s<t$, $X_s$ and $X_{t-s}$ are independent
- For any $s<t<u$, the increments $X_t-X_s$ and $X_u-X_t$ are independent

## Step 2: Show that if $(X_t)_{t\in \R^+}$ is a Brownian motion, then it satisfies the given conditions
If $(X_t)_{t\in \R^+}$ is a Brownian motion, then:
- $X_0=0$ by definition
- Since $\mathbb{E}[X_t]=0$ and ${\rm Var}(X_t)=t$, we have that $(X_t)_{t\in \R^+}$ is centered Gaussian
- We need to show that ${\rm Cov}(X_s,X_t)=\inf(s,t)$

## Step 3: Compute the covariance using the properties of Brownian motion
For any $s<t$, we can write:
${\rm Cov}(X_s,X_t) = \mathbb{E}[(X_s-\mathbb{E}[X_s])(X_t-\mathbb{E}[X_t])]$
$= \mathbb{E}[X_s X_t] - \mathbb{E}[X_s]\mathbb{E}[X_t]$
Since $\mathbb{E}[X_s]=\mathbb{E}[X_t]=0$, we have:
${\rm Cov}(X_s,X_t) = \mathbb{E}[X_s X_t]$

## Step 4: Use the independence of increments to compute the covariance
Using the property that $X_s$ and $X_{t-s}$ are independent, we can write:
$\mathbb{E}[X_s X_t] = \mathbb{E}[X_s]\mathbb{E}[X_{t-s}+X_s]$
Since $\mathbb{E}[X_s]=0$, we have:
$\mathbb{E}[X_s X_t] = \mathbb{E}[X_s^2]$

## Step 5: Compute the variance of $X_s$ to obtain the covariance
We know that ${\rm Var}(X_s)=s$. Since $(X_t)_{t\in \R^+}$ is centered Gaussian, we have:
${\rm Var}(X_s) = s$
Therefore:
$\mathbb{E}[X_s^2] = {\rm Var}(X_s) + (\mathbb{E}[X_s])^2 = s$

## Step 6: Conclude that the covariance equals $\inf(s,t)$
Since $s\leq t$, we have:
${\rm Cov}(X_s,X_t) = \mathbb{E}[X_s X_t] = \mathbb{E}[X_s^2] = s$
Therefore, ${\rm Cov}(X_s,X_t)=\inf(s,t)$.

## Step 7: Show the converse
Conversely, suppose that $(X_t)_{t\in \R^+}$ satisfies $X_0=0$, is centered Gaussian, and has covariance function ${\rm Cov}(X_s,X_t)=\inf(s,t)$. We need to show that it is a Brownian motion.

## Step 8: Show that the process has independent increments
For any $s<t<u$, we can write:
${\rm Cov}(X_u-X_t, X_t-X_s) = {\rm Cov}(X_u,X_t)-{\rm Cov}(X_u,X_s)-{\rm Cov}(X_t,X_s)+{\rm Cov}(X_s,X_s)$
$= \inf(u,t) - \inf(u,s) - \inf(t,s) + s$
Since $s<t<u$, we have:
$\inf(u,t)=t, \quad \inf(u,s)=s, \quad \inf(t,s)=s$
Therefore:
${\rm Cov}(X_u-X_t, X_t-X_s) = t-s-s+s=0$

## Step 9: Conclude that the process is a Brownian motion
Since ${\rm Cov}(X_u-X_t, X_t-X_s)=0$, we have that $X_u-X_t$ and $X_t-X_s$ are independent. Therefore, $(X_t)_{t\in \R^+}$ has independent increments.

## Step 10: Compute the variance of the process
We know that ${\rm Cov}(X_s,X_t)=s$. Since $(X_t)_{t\in \R^+}$ is centered Gaussian, we have:
${\rm Var}(X_t) = t$

## Step 11: Conclude that the process is a Brownian motion
Since $X_0=0$, $(X_t)_{t\in \R^+}$ has independent increments and ${\rm Var}(X_t)=t$, we conclude that $(X_t)_{t\in \R^+}$ is a Brownian motion.

The final answer is: $\boxed{1}$
