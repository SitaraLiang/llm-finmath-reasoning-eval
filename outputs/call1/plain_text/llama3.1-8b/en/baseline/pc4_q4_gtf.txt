Question 1:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau)$.

Answer:
## Step 1: Recall the properties of Brownian Motion
The expected value of a Brownian Motion at any time $t$, denoted as $\E(W_t)$, is zero for all $t \geq 0$.

## Step 2: Apply the property to the stopping time
Since $\tau$ is a bounded stopping time and given that the expected value of a Brownian Motion at any time is zero, we can directly apply this property to find the expected value of the Brownian Motion at the stopping time $\tau$. Therefore, $\E(W_\tau) = 0$.

The final answer is: $\boxed{0}$

Question 2:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau^2)$.

Answer:
## Step 1: Recall the properties of Brownian Motion
Brownian motion $(W_t)_{t\geq 0}$ has the property that it is a martingale, meaning its expected value at any time $t$ is equal to its initial value.

## Step 2: Apply Doob's Optional Stopping Theorem for $\E(W_\tau^2)$
Since $(W_t)_{t\geq 0}$ is a martingale and $\tau$ is a bounded stopping time, we can apply Doob's optional stopping theorem to find the expected value of $W_\tau^2$. However, this directly doesn't give us the result for $E(W_\tau^2)$ but knowing that Brownian motion has independent increments and is normally distributed with mean 0 and variance $\sigma^2 t$, we can use properties of expectation.

## Step 3: Use the property of variance
The variance of a Brownian Motion at time $t$ is given by $\Var(W_t) = \sigma^2 t$. Since $W_\tau$ is essentially $W_t$ evaluated at the stopping time $\tau$, we can use this property to find $\E(W_\tau^2)$.

## Step 4: Compute $\E(W_\tau^2)$
Given that $\Var(W_t) = \sigma^2 t$, and knowing that for a random variable $X$, $\Var(X) = E(X^2) - (E(X))^2$, we can find $\E(W_\tau^2)$ by using the fact that $W_t$ is a martingale, thus its mean is 0. Therefore, $\E(W_\tau^2) = \Var(W_\tau) + (\E(W_\tau))^2$. Since $\E(W_\tau) = 0$, we have $\E(W_\tau^2) = \Var(W_\tau)$.

## Step 5: Apply the property of variance for Brownian Motion
Since $W_t$ is a Brownian motion, its variance at time $t$ is given by $\sigma^2 t$. Therefore, $\Var(W_\tau) = \sigma^2 \tau$, and since we are looking for $\E(W_\tau^2)$ which equals to the variance of $W_\tau$, we have $\E(W_\tau^2) = \sigma^2 \tau$.

The final answer is: $\boxed{\sigma^2 \tau}$
