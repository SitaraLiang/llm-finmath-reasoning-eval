Question 1:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau)$.

Answer:
$\E(W_\tau) = \int_{-\infty}^{\infty} x f(x, \tau) dx$

where $f(x, \tau)$ is the density of $W_\tau$.

Since $\tau$ is a bounded stopping time, there exists a constant $T$ such that $\tau \leq T$ almost surely.

Using the properties of Brownian Motion, we have:

$f(x, \tau) = \frac{1}{\sqrt{2\pi \tau}} e^{-\frac{x^2}{2\tau}}$

Substituting this into the integral, we get:

$\E(W_\tau) = \int_{-\infty}^{\infty} x \frac{1}{\sqrt{2\pi \tau}} e^{-\frac{x^2}{2\tau}} dx$

Using integration by parts, we can evaluate this integral as follows:

$\E(W_\tau) = 0$

Question 2:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau^2)$.

Answer:
$\E(W_\tau^2) = \int_0^\infty W_t^2 \frac{\partial}{\partial t} P(\tau > t) dt$

Since $P(\tau > t) = 1$ for all $t$, we have:

$\E(W_\tau^2) = \int_0^\infty W_t^2 dt$

Using the properties of Brownian Motion, we know that $\E[W_t^2] = t$. Therefore,

$\E(W_\tau^2) = \int_0^\infty t dt = \frac{1}{2} \tau^2$
