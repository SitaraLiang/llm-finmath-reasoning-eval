Question 1:
Show that a process $(X_t)_{t\in \R^+}$ is a Brownian motion if and only if: $X_0=0$, $(X_t)_{t\in \R^+}$ is a centered Gaussian process, ${\rm Cov}(X_s,X_t)=\inf(s,t).$

Answer:
## Step 1: Recall the definition of Brownian motion
A stochastic process $(X_t)_{t\in \R^+}$ is a Brownian motion if it satisfies the following properties:
- $X_0=0$ almost surely,
- For all $s,t\geq 0$, $\mathbb{E}[X_s]=\mathbb{E}[X_t]=0$,
- For all $s<t$, $X_t-X_s \sim \mathcal{N}(0, t-s)$ and is independent of $(X_u)_{u<s}$.

## Step 2: Show that if $(X_t)_{t\in \R^+}$ is a Brownian motion, then it satisfies the given conditions
If $(X_t)_{t\in \R^+}$ is a Brownian motion, then:
- $X_0=0$ by definition,
- Since $\mathbb{E}[X_s]=\mathbb{E}[X_t]=0$, we have that $(X_t)_{t\in \R^+}$ is centered Gaussian,
- For all $s<t$, ${\rm Cov}(X_s,X_t)=\mathbb{E}[(X_t-X_s)(X_t-X_s)] = \mathbb{E}[X_t^2]-\mathbb{E}[X_s^2]=t-s$.

## Step 3: Show that if $(X_t)_{t\in \R^+}$ satisfies the given conditions, then it is a Brownian motion
If $(X_t)_{t\in \R^+}$ satisfies the given conditions:
- $X_0=0$,
- $(X_t)_{t\in \R^+}$ is centered Gaussian,
- ${\rm Cov}(X_s,X_t)=\inf(s,t)$,
then for all $s<t$, we have that
$\mathbb{E}[(X_t-X_s)^2] = {\rm Var}(X_t-X_s)={\rm Cov}(X_t,X_t)-{\rm Cov}(X_s,X_t)=t-s$.
This implies that $(X_t-X_s) \sim \mathcal{N}(0, t-s)$ and is independent of $(X_u)_{u<s}$.

The final answer is: $\boxed{1}$

Question 2:
Show that if $W_t$ is a Brownian motion, $ \{X_t=t\;W_{\frac 1t}, t>0, X_0=0 \}$ is a Brownian motion too.

Answer:
## Step 1: Recall the definition of a Brownian motion
A process $(W_t)_{t\in \R^+}$ is a Brownian motion if it satisfies:
- $W_0=0$
- $(W_t)_{t\in \R^+}$ is a centered Gaussian process
- ${\rm Cov}(W_s,W_t)=\inf(s,t)$

## Step 2: Define the given process
Let $X_t=t\;W_{\frac{1}{t}}$ for $t>0$, and $X_0=0$.

## Step 3: Check if $X_t$ is centered Gaussian
Since $W_{\frac{1}{t}}$ is a Brownian motion, it is a centered Gaussian process. Therefore, $t\;W_{\frac{1}{t}}$ is also centered Gaussian for each fixed $t$, since the product of a constant and a Gaussian random variable is Gaussian.

## Step 4: Compute the covariance of $X_s$ and $X_t$
We have:
${\rm Cov}(X_s,X_t) = {\rm Cov}\left(s\;W_{\frac{1}{s}}, t\;W_{\frac{1}{t}} \right)$
$= st\;{\rm Cov}\left(W_{\frac{1}{s}}, W_{\frac{1}{t}} \right)$
$= st\;\inf\left(\frac{1}{s},\frac{1}{t} \right)$
$= \min(s,t)$

## Step 5: Check the initial condition of $X_t$
We have $X_0 = 0$, as given.

The final answer is: $\boxed{1}$
