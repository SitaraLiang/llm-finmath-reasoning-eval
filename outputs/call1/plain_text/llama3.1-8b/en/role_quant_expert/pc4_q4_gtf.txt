Question 1:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau)$.

Answer:
## Step 1: Recall the definition of a Brownian Motion
A Brownian Motion $W_t$ satisfies the following properties:
- $W_0 = 0$
- $W_t - W_s \sim \mathcal{N}(0, t-s)$ for $t > s$
- The increments are independent

## Step 2: Use the linearity of expectation
We can write $\E(W_\tau) = \E(\E(W_\tau | \mathcal{F}_\tau))$ where $\mathcal{F}_\tau$ is the filtration generated by $W_t$ up to time $\tau$

## Step 3: Apply the conditional expectation formula for a Brownian Motion
Since $W_t$ is a martingale, we have that $\E(W_\tau | \mathcal{F}_t) = W_t$ for any $t < \tau$. Therefore, taking the limit as $t \to \tau$, we get $\E(W_\tau | \mathcal{F}_\tau) = W_\tau$

## Step 4: Use the fact that $W_\tau$ is a random variable with zero mean
Since $W_t$ has zero mean for all $t$, it follows that $\E(W_\tau) = \E(\E(W_\tau | \mathcal{F}_\tau)) = \E(W_\tau)$

## Step 5: Compute the expectation of $W_\tau$
Using the fact that $W_t$ has zero mean, we have that $\E(W_\tau) = 0$

The final answer is: $\boxed{0}$

Question 2:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau^2)$.

Answer:
## Step 1: Recall the properties of Brownian Motion
Brownian motion $(W_t)_{t\geq 0}$ has the property that it is a martingale, meaning its expected value at any time $t$ is equal to its initial value.

## Step 2: Apply Doob's optional stopping theorem
Since $\tau$ is a bounded stopping time and $(W_t)_{t\geq 0}$ is a martingale, we can apply Doob's optional stopping theorem. This theorem states that for a martingale $(X_t)_{t\geq 0}$ and a bounded stopping time $\tau$, the expected value of $X_\tau$ is equal to the initial value of $X_0$. For Brownian motion, its initial value is 0.

## Step 3: Compute $\E(W_\tau^2)$
However, for the second moment, we cannot directly apply Doob's optional stopping theorem because it does not hold for all martingales. Instead, we use the property that $W_t$ has independent increments and each increment is normally distributed with mean 0 and variance equal to its time. Therefore, $\E(W_\tau^2) = \int_0^\infty \E(W_s^2 | s < \tau) dP(s < \tau)$.

## Step 4: Simplify the expression
Since $W_t$ has independent increments, we can simplify this to $\E(W_\tau^2) = \int_0^\infty E(W_s^2) dP(s < \tau)$. We know that for a Brownian motion, $\E(W_s^2) = s$.

## Step 5: Evaluate the integral
Therefore, we have $\E(W_\tau^2) = \int_0^\infty s dP(s < \tau)$.

## Step 6: Use Fubini's theorem to change the order of integration
We can use Fubini's theorem to change the order of integration. This gives us $\E(W_\tau^2) = \int_0^\infty P(\tau > s) ds$.

## Step 7: Evaluate the integral
Since $\tau$ is a bounded stopping time, $P(\tau > s)$ is equal to 1 for all $s < \tau_{max}$ and 0 otherwise. Therefore, we have $\E(W_\tau^2) = \int_0^{\tau_{max}} ds = \tau_{max}$.

## Step 8: Simplify the expression
Since $\tau$ is a bounded stopping time, it has a finite maximum value $\tau_{max}$. Therefore, we can simplify this to $\E(W_\tau^2) = \tau_{max}$.

The final answer is: $\boxed{\tau_{max}}$
