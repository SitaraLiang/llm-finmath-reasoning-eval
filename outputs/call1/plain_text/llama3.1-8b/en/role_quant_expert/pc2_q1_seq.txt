Question 1:
Show that a process $(X_t)_{t\in \R^+}$ is a Brownian motion if and only if: $X_0=0$, $(X_t)_{t\in \R^+}$ is a centered Gaussian process, ${\rm Cov}(X_s,X_t)=\inf(s,t).$

Answer:
## Step 1: Recall the definition of a Brownian motion
A Brownian motion is a stochastic process $(X_t)_{t\in \R^+}$ that satisfies:
- $X_0=0$
- For any $s<t$, $X_t-X_s$ is independent of $\{X_u, u\leq s\}$
- For any $s<t$, $X_t-X_s$ has a normal distribution with mean 0 and variance $t-s$

## Step 2: Show that if $(X_t)_{t\in \R^+}$ is a Brownian motion, then it satisfies the given conditions
If $(X_t)_{t\in \R^+}$ is a Brownian motion:
- By definition, $X_0=0$
- Since for any $s<t$, $X_t-X_s$ has a normal distribution with mean 0 and variance $t-s$, it follows that the process is centered Gaussian
- The covariance between $X_s$ and $X_t$ can be computed as:
\[{\rm Cov}(X_s,X_t) = {\rm Cov}(X_s, X_s + (X_t - X_s))\]
\[= {\rm Cov}(X_s, X_s) + {\rm Cov}(X_s, X_t - X_s)\]
\[= \sigma^2(s) + 0\]
\[= s\]
where $\sigma^2(t)$ is the variance of $X_t$. However, we need to show that ${\rm Cov}(X_s,X_t)=\inf(s,t)$. This can be done by considering two cases: (i) $s<t$ and (ii) $t<s$. For case (i), using the properties of Brownian motion:
\[{\rm Cov}(X_s,X_t) = {\rm Cov}(X_s, X_s + (X_t - X_s))\]
\[= {\rm Cov}(X_s, X_s) + {\rm Cov}(X_s, X_t - X_s)\]
\[= s + 0\]
\[= \inf(s,t)\]
For case (ii), we can use the fact that Brownian motion has stationary increments and is a martingale:
\[{\rm Cov}(X_s,X_t) = {\rm Cov}(X_t, X_t + (X_s - X_t))\]
\[= {\rm Cov}(X_t, X_t) + {\rm Cov}(X_t, X_s - X_t)\]
\[= t + 0\]
\[= \inf(s,t)\]

## Step 3: Show that if $(X_t)_{t\in \R^+}$ satisfies the given conditions, then it is a Brownian motion
If $(X_t)_{t\in \R^+}$ satisfies:
- $X_0=0$
- It is centered Gaussian
- ${\rm Cov}(X_s,X_t)=\inf(s,t)$
Then for any $s<t$, we have:
\[{\rm Var}(X_t - X_s) = {\rm Var}(X_t) + {\rm Var}(X_s) - 2{\rm Cov}(X_s, X_t)\]
\[= t + s - 2\inf(s,t)\]
\[= |t-s|\]
This implies that $X_t-X_s$ has a normal distribution with mean 0 and variance $|t-s|$.
Moreover, since the process is centered Gaussian, it follows that for any $s<t$, $X_t-X_s$ is independent of $\{X_u, u\leq s\}$.

The final answer is: $\boxed{1}$

Question 2:
Show that if $W_t$ is a Brownian motion, $ \{X_t=t\;W_{\frac 1t}, t>0, X_0=0 \}$ is a Brownian motion too.

Answer:
## Step 1: Recall the definition of a Brownian motion
A stochastic process $\{W_t, t \geq 0\}$ is called a Brownian motion if it satisfies the following properties:
- $W_0 = 0$ almost surely,
- The increments are independent, i.e., for any $s < t$, $W_t - W_s$ is independent of $\mathcal{F}_s^W = \sigma(W_u : u \leq s)$,
- For any $t > 0$, $W_t - W_s \sim \mathcal{N}(0, t-s)$.

## Step 2: Verify the first property
We have that $X_0 = 0$ by definition of the process $\{X_t\}$.

## Step 3: Verify the second property
Let $s < t$. Then we need to show that $X_t - X_s$ is independent of $\mathcal{F}_s^{X} = \sigma(X_u : u \leq s)$. Since $W_{\frac{1}{u}}$ is a function of the Brownian motion, it is also a martingale. Therefore, for any $u < v$, $W_{\frac{v}{u}} - W_{\frac{v}{s}}$ is independent of $\mathcal{F}_{\frac{v}{u}}^{W} = \sigma(W_w : w \leq \frac{v}{u})$. Since $X_t - X_s = (t-s)W_{\frac{1}{t}} - (s-t)W_{\frac{1}{s}}$, we have that $X_t - X_s$ is independent of $\mathcal{F}_s^{X}$.

## Step 4: Verify the third property
For any $t > 0$, we need to show that $X_t \sim \mathcal{N}(0, t)$. We have that $W_{\frac{1}{t}} \sim \mathcal{N}(0, \frac{1}{t})$ by definition of the Brownian motion. Therefore, $t W_{\frac{1}{t}} \sim \mathcal{N}(0, t)$.

The final answer is: $\boxed{1}$
