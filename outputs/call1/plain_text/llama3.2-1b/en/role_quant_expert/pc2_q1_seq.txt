Question 1:
Show that a process $(X_t)_{t\in \R^+}$ is a Brownian motion if and only if: $X_0=0$, $(X_t)_{t\in \R^+}$ is a centered Gaussian process, ${\rm Cov}(X_s,X_t)=\inf(s,t).$

Answer:
To show that a process $(X_t)_{t\in \R^+}$ is a Brownian motion if and only if $X_0=0$, $(X_t)_{t\in \R^+}$ is a centered Gaussian process, ${\rm Cov}(X_s,X_t)=\inf(s,t),$ we need to prove two statements:

1. If $(X_t)_{t\in \R^+}$ is a Brownian motion, then $X_0=0$ and it satisfies the specified covariance properties.

2. If $X_0=0$ and $(X_t)_{t\in \R^+}$ satisfies the specified covariance properties, then it is a centered Gaussian process.

Since we are not provided with any specific definitions of Brownian motion or centered Gaussian process other than these two conditions, we can use the standard definitions from stochastic calculus:

- A process $(X_t)_{t\in \R^+}$ is called a Brownian motion if:
  - $X_0=0$ (starting at zero)
  - For any $s<t$, ${\rm Var}(X_s-X_t)=s-t$

- A centered Gaussian process has finite mean $\mu=\E(X_t)$, and its covariance function satisfies ${\rm Cov}(X_s,X_t)=\E(X_s X_t) - \mu^2$.

Given these definitions, the first statement is evident since a Brownian motion by definition starts at zero.

For the second statement, suppose $(X_t)_{t\in \R^+}$ is a centered Gaussian process with $X_0=0$. We want to show that ${\rm Cov}(X_s,X_t)=\inf(s,t)$.

Using Ito's formula for local martingales and taking expectations at zero, we have:

$$
\E[(X_s-X_t)^2]=s-t+\E(X_s X_t)-\mu^2.
$$

Since $X_0=0$, the last term vanishes. For any $t<\inf(s,t)$, $\E((X_s-X_t)^2)<s-t$ due to the tail risk being at least as large as $s-t$. Taking expectations at zero:

$$
\int_{0}^{\infty} \E[(X_s-X_t)^2] dP(t) = t.
$$

Therefore, $\inf(s,t)=t$, which means that $(X_t)_{t\in \R^+}$ is a centered Gaussian process.

Question 2:
Show that if $W_t$ is a Brownian motion, $ \{X_t=t\;W_{\frac 1t}, t>0, X_0=0 \}$ is a Brownian motion too.

Answer:
To show that $\{X_t = t W_{\frac 1t}, t > 0, X_0 = 0\}$ is a Brownian motion when $W_t$ is a Brownian motion, we need to verify the following properties:

1. $X_0 = 0$
2. $X_t$ has independent increments
3. $X_t - X_s \mid \mathcal{F}_s$ are independent and normally distributed for $s < t$

Since $W_t$ is a Brownian motion, we have:

$$X_1 = W_{\frac 1t} > 0$$

As the increments of a Brownian motion are independent and identically distributed (i.i.d.), it suffices to show that $X_t - X_s \mid \mathcal{F}_s$ is normally distributed.

Since $\frac{d}{dt} X_t = t W_{\frac 1t}$, we have:

$$dX_t = dW_{\frac 1t} + t \cdot \frac{1}{2} dW_t^2$$

where $dW_t^2$ is a compound Poisson process with rate $\frac 12$. This implies that $(X_t - X_s) / (t-s)$ is normally distributed for all $s < t$, since the increments of the compound Poisson process are independent and identically distributed.

Therefore, we conclude that $\{X_t = t W_{\frac 1t}, t > 0, X_0 = 0\}$ is indeed a Brownian motion.
