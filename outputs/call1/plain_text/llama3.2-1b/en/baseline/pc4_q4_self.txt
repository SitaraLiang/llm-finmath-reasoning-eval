Question 1:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau)$.

Answer:
$\E(W_\tau) = \int_0^\infty e^{-\frac{t}{2}} \mathbb{P}(\tau < t) dt$

To evaluate this expression, we can use the fact that $\mathbb{P}(\tau < t) = \mathbb{F}_t^W$, where $\mathbb{F}$ is the filtration generated by $W$.

Using the Burkholder-Davis-Gundy (BdG) inequality, we have:

$$\E[|W_\tau|^2] \leq C_t \left( \int_0^\infty |W_s|^2 ds + \int_0^\infty (\mathbb{F}_s^W)(t) dt\right)$$

where $C$ is a constant depending only on the dimension of the space.

Since $\tau$ is a bounded stopping time, we have:

$$\E[|W_\tau|^2] = \int_0^\infty \mathbb{P}(\tau < t) dt = 1$$

and

$$\int_0^\infty (\mathbb{F}_t^W)(t) dt = \lim_{T \to \infty} \frac{1}{2} \left( \int_0^{T-1} W_s dW_s + \int_T^{\infty} (dW_s - dB_s)\right)$$

where $B$ is a Brownian motion.

Using the properties of Brownian motion, we have:

$$\int_0^{T-1} W_s dW_s = 0$$

and

$$\int_T^{\infty} (dW_s - dB_s) = \left( B_t - t \right)^2$$

Substituting these expressions into the previous equation, we get:

$$\E[|W_\tau|^2] = \frac{1}{2} \lim_{T \to \infty} \left( T + 2(T-t) \int_T^{\infty} (dB_s - W_s dW_s)\right)$$

Since $\int_T^{\infty} (dB_s - W_s dW_s)$ is a martingale, we have:

$$\E[|W_\tau|^2] = \frac{1}{2} \lim_{T \to \infty} T + 2(T-t) \E[M_T]$$

where $M$ is a martingale.

Since $\tau$ is a bounded stopping time, we have:

$$\E[M_T] = 0$$

Therefore,

$$\E[|W_\tau|^2] = \frac{1}{2} T + 2(T-t) \cdot 0 = \frac{T}{2}$$

Finally,

$$\E[W_\tau] = \int_0^\infty e^{-\frac{t}{2}} \mathbb{P}(\tau < t) dt = \sqrt{\frac{\pi}{4}} \int_0^\infty e^{-\frac{t}{2}} dt = \frac{1}{\sqrt{2}}$$
