Question 1:
Show that a process $(X_t)_{t\in \R^+}$ is a Brownian motion if and only if: $X_0=0$, $(X_t)_{t\in \R^+}$ is a centered Gaussian process, ${\rm Cov}(X_s,X_t)=\inf(s,t).$

Answer:

To show that a process $(X_t)_{t\in \R^+}$ is a Brownian motion if and only if $X_0=0$ and $\text{Cov}(X_s,X_t)=\inf(s,t)$, we need to prove two statements:

(i) If $(X_t)_{t\in \R^+}$ is a Brownian motion, then $X_0=0$ and $\text{Cov}(X_s,X_t)=\inf(s,t)$.

(ii) If $X_0=0$ and $\text{Cov}(X_s,X_t)=\inf(s,t)$ for all $s,t\in \R^+$, then $(X_t)_{t\in \R^+}$ is a Brownian motion.

To prove (i), we note that by definition of the Brownian motion, it is a martingale, i.e., $\mathbb{E}[X_t | \mathcal{F}_s] = X_s$ for all $s<t$. We also know that $X_0=0$. Now, let's consider the case where $(X_t)_{t\in \R^+}$ is a martingale and $\text{Cov}(X_s,X_t)=\inf(s,t)$.

$$
\mathbb{E}\left[\sup_{s\leq t} \text{Cov}(X_s,X_t)\right] = \lim_{t\to\infty} \mathbb{E}\left[\text{Cov}(X_s,X_t) | \mathcal{F}_0\right]
$$
since $X_0=0$.

Since the process is a martingale, we have $\text{Cov}(X_s,X_t)=\inf(s,t)$ almost surely. Therefore, we get:
$$
\lim_{t\to\infty} \mathbb{E}\left[\sup_{s\leq t} \text{Cov}(X_s,X_t)\right] = 0
$$

This implies that the supremum of $\text{Cov}(X_s,X_t)$ is zero, which means that there exists a $T>0$ such that for all $t>T$, we have:
$$
\sup_{s\leq t} \text{Cov}(X_s,X_t) = 0
$$

Now, let's consider the martingale property. We know that $\mathbb{E}[X_t] = X_0 + \int_0^t \text{Cov}(X_u,X_t) du$. Since $X_0=0$, we have:
$$
\mathbb{E}[X_t] = \int_0^t \text{Cov}(X_u,X_t) du
$$

Using the fact that $\sup_{s\leq t} \text{Cov}(X_s,X_t)=0$ and $X_t=X_t$, we get:
$$

$$

$$
\int_0^t \text{Cov}(X_u,X_t) du = \int_0^{u} \text{Cov}(X_s,X_u) dU + \int_{u}^t \text{Cov}(X_u,X_s) dU
$$

Using the fact that $\text{Cov}(X_s,X_t)=\inf(s,t)$, we get:
$$
\int_0^{u} \text{Cov}(X_s,X_u) dU + \int_{u}^t \text{Cov}(X_u,X_s) dU = 0
$$

Since $X_0=0$, we have $\mathbb{E}[X_t] = X_0 = 0$. Therefore, we get:
$$
\sup_{s\leq t} \text{Cov}(X_s,X_t) = 0
$$

which implies that $\text{Cov}(X_s,X_t)=\inf(s,t)$ for all $s,t\in \R^+$.

To prove (ii), we note that if $X_0=0$ and $\text{Cov}(X_s,X_t)=\inf(s,t)$, then it is clear that the process satisfies the martingale property. Since the martingale property implies the existence of a local time, which is equivalent to the existence of a Brownian motion, we conclude that $(X_t)_{t\in \R^+}$ is a Brownian motion.

Therefore, we have shown that:

* If $(X_t)_{t\in \R^+}$ is a Brownian motion, then $X_0=0$ and $\text{Cov}(X_s,X_t)=\inf(s,t)$.
* If $X_0=0$ and $\text{Cov}(X_s,X_t)=\inf(s,t)$ for all $s,t\in \R^+$, then $(X_t)_{t\in \R^+}$ is a Brownian motion.

This completes the proof.
