Question 1:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau)$.

Answer:
## Step 1: Recall the definition of the expected value for a stochastic process
The expected value of a stochastic process $W_t$ at time $\tau$, denoted by $\E(W_\tau)$, is given by:

$$\E(W_\tau) = \int_{-\infty}^{\infty} f(x|\theta) x d\mathbb{P}(\theta),$$

where $f(x|\theta)$ is the density function of $W_t$ at time $\tau$, and $\mathbb{P}(\theta)$ is the probability measure corresponding to a bounded stopping time $\tau$.

## Step 2: Apply the properties of Brownian Motion
For a Brownian Motion $W_t$, we know that it has continuous paths, and for any bounded stopping time $\tau$, the increments $W_\tau - W_{\tau -}^-$ are independent and identically distributed normal random variables with mean 0 and variance equal to the increment's size.

## Step 3: Use the Optional Stopping Theorem
By the Optional Stopping Theorem, we have:

$$E(W_\tau) = \lim_{T \to \infty} E[W_T | W_0 = 0] = \lim_{T \to \infty} \frac{1}{\sqrt{T}} E(W_T).$$

## Step 4: Evaluate the expectation of $W_T$
Using the Itô's formula for a Brownian Motion, we have:

$$E(W_T) = T + \frac{1}{2}T^2 + \ldots,$$

which is an infinite series.

## Step 5: Apply the Laplace transform
We can apply the Laplace transform to both sides of the equation:

$$\mathbb{E}(W_\tau) = \lim_{T \to \infty} \frac{\sqrt{T}}{(s - T)^2},$$

where $s$ is a complex number.

## Step 6: Evaluate the limit
Taking the limit as $T \to \infty$, we get:

$$\mathbb{E}(W_\tau) = \lim_{T \to \infty} \frac{\sqrt{T}}{(s - T)^2} = \sigma_s,$$

where $\sigma_s$ is the covariance function of a Brownian Motion.

## Step 7: Simplify using Ito's formula
Using Ito's formula, we have:

$$\E(W_\tau) = \int_{-\infty}^{\infty} f(x|\theta) x d\mathbb{P}(\theta).$$

Since $W_t$ is a Brownian Motion, its mean and covariance functions are constant over time. Therefore, we can rewrite the integral as:

$$\E(W_\tau) = \int_{-\infty}^{\infty} f(x|\sigma_s) x d\mathbb{P}(\theta).$$

## Step 8: Simplify using the Itô's formula for Brownian Motion
Using Ito's formula, we have:

$$f(x|\sigma_s) = \frac{1}{2}x^2 + \ldots,$$

where $\ldots$ represents terms with negative powers of $x$.

## Step 9: Evaluate the integral
Evaluating the integral, we get:

$$\E(W_\tau) = \int_{-\infty}^{\infty} (\frac{1}{2}x^2 + \ldots)x d\mathbb{P}(\theta).$$

## Step 10: Simplify using the properties of Brownian Motion
Using the properties of Brownian Motion, we know that:

$$E(W_\tau) = T + \frac{T^2}{3}.$$

## Step 11: Evaluate the limit
Taking the limit as $T \to \infty$, we get:

$$\E(W_\tau) = \sigma_s.$$

The final answer is: $\boxed{\sigma_s}$

Question 2:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau^2)$.

Answer:
$\E[W_\tau^2] = \int_0^\tau (W_s)^2 ds$

Since $W_t$ is a Brownian Motion, we have the following properties:

\begin{align*}
\dfrac{d}{dt} W_t &= \mathbb{I}_{\{t \leq \tau\}} dW_{\tau}\\
W_\tau - W_s &= (\tau-s) W_\tau + (s-W_s) \\
(W_\tau)^2 - 2(W_\tau)(W_\tau-S) &=(\tau-s) W_\tau + (s-W_\tau)^2.
\end{align*}

Taking expectation, we get:

$$
\begin{aligned}
\dfrac{d}{dt} \E[W_\tau^2] &= \mathbb{I}_{\{t \leq \tau\}} d(\E[W_\tau]) \\
&= (\tau-s) \E[W_\tau] + \E[(s-W_\tau)^2] \\
&= (\tau-s) \E[W_\tau]
\end{aligned}
$$

Similarly, we can derive the following:

$ $

$$
\dfrac{d}{dt} \E[W_\tau^2] = 0
$$

Integrating both sides from $0$ to $\tau$, we get:

$\begin{aligned}
\E[W_\tau^2] &= \int_0^\tau (W_s)^2 ds \\
&= (\tau-s) W_\tau + \frac{s(s-1)}{2} \E[W_\tau] \\
&= sW_\tau + \frac{s(s-1)}{2} \E[W_\tau]
\end{aligned}$

Since $W_t$ is a Brownian Motion, we have the following property:

$$
\dfrac{d}{dt} W_t = \mathbb{I}_{\{t < T\}} dW_T + \mathbb{I}_{\{T \leq t\}} dW_{t-T}
$$

Since $T$ is a bounded stopping time, we have:

$$
\dfrac{d}{dt} W_t = 0 \text{ if } t < T
$$

Therefore,

$\begin{aligned}
\E[W_\tau^2] &= sW_\tau + \frac{s(s-1)}{2} \E[W_\tau] \\
&= (\tau-s) W_\tau + \frac{\tau(\tau-1)}{2} \E[W_\tau]
\end{aligned}$

Simplifying the expression, we get:

$\begin{aligned}
\E[W_\tau^2] &= \int_0^\tau (W_s)^2 ds \\
&= \frac{(\tau-\tau+1)\tau}{3}\E[W_\tau]^2 + \frac{\tau(\tau-1)}{6} \E[W_\tau]^2
\end{aligned}$

Rearranging the terms, we get:

$\begin{aligned}
\E[W_\tau^2] &= \left(\frac{1}{3}\E[W_\tau]^2 + \frac{\tau}{6}\right)\tau \\
&= \left(\frac{\tau+\tau^2}{6}\right)\tau
\end{aligned}$
