Question 1:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau)$.

Answer:
## Step 1: Recall the definition of Brownian Motion
The Brownian Motion $W_t$ is a continuous stochastic process with independent increments, and it satisfies the following properties:
- $W_0 = 0$
- $\mathbb{E}(W_{t+1} - W_t) = \frac{1}{2}\text{Var}(W_t)$
- $W_t$ has stationary and independent increments.

## Step 2: Recall the Martingale Representation
Since $\tau$ is a bounded stopping time, we can write:
\[W_\tau = W_0 + \int_{0}^{\tau} B_s ds\]
where $B_s$ is a Brownian Motion with zero mean and unit variance.

## Step 3: Compute the expected value of $W_\tau$
Using the martingale representation, we have:
\[\E(W_\tau) = \E[W_0 + \int_{0}^{\tau} B_s ds]\]
Since $\E(B_s) = 0$ and $\mathbb{E}(B_s^2) = \text{Var}(B_s)$ for any Brownian Motion, we have:
\[\E(W_\tau) = \E[W_0] + \int_{0}^{\tau} \E[B_s] ds\]
Since $W_0 = 0$, the first term is zero. For the second term, since $\mathbb{E}(B_s^2) = \text{Var}(B_s)$, we have:
\[\E[W_\tau] = \int_{0}^{\tau} \text{Var}(B_s) ds\]

## Step 4: Simplify the expression
Since $B_0 = 0$ and $\mathbb{E}(B_s^2) = \text{Var}(B_s)$ for any Brownian Motion, we have:
\[\E[W_\tau] = \int_{0}^{\tau} \text{Var}(B_s) ds = \tau \cdot \text{Var}(B_s)\]

## Step 5: Take the expectation of $W_t$ over the stopping time $\tau$
Using the expression for $\E(W_\tau)$ obtained in Step 4, we have:
\[\E(W_\tau) = \int_{0}^{\tau} W_s ds\]
Since $B_0 = 0$, we can write:
\[W_0 = B_t - B_0 = B_t\]
Therefore, we have:
\[\E(W_\tau) = \int_{0}^{\tau} (B_s + B_t) ds\]

## Step 6: Simplify the expression
Since $B_0 = 0$, we can write:
\[W_0 = B_t - B_0 = B_t\]
Therefore, we have:
\[\E(W_\tau) = \int_{0}^{\tau} (B_s + B_t) ds = \frac{1}{2}\text{Var}(B_s) + \frac{1}{2}B_t + \frac{1}{2}B_0 = \frac{1}{2}\text{Var}(B_s) + \frac{1}{2}B_t\]

## Step 7: Take the expectation of $W_\tau$ over the stopping time $\tau$
Using the expression for $\E(W_\tau)$ obtained in Step 6, we have:
\[\E(W_\tau) = \int_{0}^{\tau} W_s ds\]
Since $\mathbb{E}(B_s^2) = \text{Var}(B_s)$ for any Brownian Motion and $W_0 = B_t$, we can write:
\[W_0 = B_t - B_0 = B_t\]

## Step 8: Compute the expected value
Using the expression for $\E(W_\tau)$ obtained in Step 7, we have:
\[\E(W_\tau) = \int_{0}^{\tau} W_s ds = \frac{1}{2}\text{Var}(W_\tau)\]

## Step 9: Simplify the expression
Since $B_0 = 0$, we can write:
\[W_t = B_t + B_0\]
Therefore, we have:
\[\E(W_\tau) = \int_{0}^{\tau} W_s ds = \frac{1}{2}\text{Var}(W_\tau)\]

## Step 10: Simplify the expression
Using the martingale representation, we have:
\[W_\tau = W_0 + \int_{0}^{\tau} B_s ds\]
Since $B_0 = 0$, we can write:
\[W_\tau = W_0 + \int_{0}^{\tau} B_s ds = W_t - B_0 = W_t\]

## Step 11: Compute the expected value
Using the expression for $\E(W_\tau)$ obtained in Step 10, we have:
\[\E(W_\tau) = \frac{1}{2}\text{Var}(W_\tau)\]

The final answer is: $\boxed{\frac{1}{2}\text{Var}(W_\tau)}$

Question 2:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau^2)$.

Answer:
## Step 1: Recall the definition of Brownian Motion
The Brownian Motion $W_t$ is a continuous stochastic process with independent increments, and it satisfies the following properties:
- $W_0 = 0$
- $\mathbb{E}(W_{t+1} - W_t) = \frac{1}{2}\text{Var}(W_t)$
- $W_t$ has stationary and independent increments.

## Step 2: Recall the Delta-Epsilon theorem
The Delta-Epsilon theorem states that for a stopping time $\tau$, we have:
\[\E(W_{\tau}^2) = \E(\mathbb{I}_{\{\tau > t\}} W_t^2)\]

## Step 3: Apply the Delta-Epsilon theorem
Since $W_0 = B_t$ and $B_0 = 0$, we have:
\[W_\tau = B_\tau - B_0 = B_\tau\]
Therefore, we can write:
\[\E(W_{\tau}^2) = \E(\mathbb{I}_{\{\tau > t\}} (B_\tau)^2)\]

## Step 4: Simplify the expression
Since $\mathbb{E}(B_s^2) = \text{Var}(B_s)$ for any Brownian Motion, we have:
\[\E(W_{\tau}^2) = \int_{0}^{\tau} (B_\sigma)^2 ds\]

## Step 5: Compute the expected value
Using the martingale representation and the properties of Brownian Motion, we can write:
\[W_\tau = B_\tau - B_0 = B_\tau\]
Therefore, we have:
\[\E(W_{\tau}^2) = \int_{0}^{\tau} (B_\sigma)^2 ds = \frac{1}{2}\text{Var}(B_\tau)\]

## Step 6: Simplify the expression
Since $B_0 = 0$, we can write:
\[W_t = B_t + B_0\]
Therefore, we have:
\[\E(W_{\tau}^2) = \frac{1}{2}\text{Var}(W_\tau)\]

The final answer is: $\boxed{\frac{1}{2}\text{Var}(W_\tau)}$
