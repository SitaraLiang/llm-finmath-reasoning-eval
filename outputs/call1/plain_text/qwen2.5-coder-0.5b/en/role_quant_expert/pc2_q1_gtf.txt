Question 1:
Show that a process $(X_t)_{t\in \R^+}$ is a Brownian motion if and only if: $X_0=0$, $(X_t)_{t\in \R^+}$ is a centered Gaussian process, ${\rm Cov}(X_s,X_t)=\inf(s,t).$

Answer:
To show that a process \((X_t)_{t\in \mathbb{R}^+}\) is a Brownian motion if and only if \(X_0 = 0\) and \(\text{Cov}(X_s, X_t) = \inf(s, t)\), we need to prove the following two cases:

**Case 1: \(X_0 = 0\)**

If \(X_0 = 0\), then \((X_t)_{t \in \mathbb{R}^+}\) is a centered Gaussian process. This means that there exists a constant \(\mu\) such that:

\[ X_s = X_0 + s \cdot \mu \quad \text{for all } s \in \mathbb{R}. \]

The covariance matrix of \((X_t)\) with respect to \(s\) is given by the following expression:

\[ \text{Cov}(X_s, X_t) = \int_{0}^t \int_{0}^s \mu (x - x') \cdot \mu (y - y') \, dx \, dy. \]

We can separate the integrals and use integration by parts to simplify this expression:

\[ \text{Cov}(X_s, X_t) = \int_{0}^t (\mu (x - x')) \int_{0}^s \mu (y - y') \, dx \, dy = \int_{0}^t (\mu^2 + \mu x' \cdot \mu + x'y') \int_{0}^s (1 - \mu) \, dx \, dy. \]

\[ \text{Cov}(X_s, X_t) = \int_{0}^t (\mu^2 + 2\mu x' \cdot \mu + s \mu y') \, dx \, dy = \int_{0}^t (\mu^2 + 2s \mu y') \, dx \, dy. \]

Since the integrand is an exponential function and the limits of integration are from 0 to \(t\), we have:

\[ \text{Cov}(X_s, X_t) = \int_{0}^{t} e^{-\frac{s}{2}} (1 - \mu) \, dx. \]

This integral converges to zero as \(s\) approaches infinity if the mean of \(\text{e}^{-\frac{s}{2}}\) is zero, which occurs when \(\int_{0}^t e^{-\frac{s}{2}} = 1\). Therefore, if \(X_0 = 0\), then \((X_t)\) is a centered Gaussian process with mean \(\mu = 0\).

**Case 2: \(\text{Cov}(X_s, X_t) = \inf(s, t)\)**

If \(\text{Cov}(X_s, X_t) = \inf(s, t)\), then:

\[ \int_{0}^t \int_{0}^s \mu (x - x') \cdot \mu (y - y') \, dx \, dy = \int_{0}^t (\mu^2 + 2\mu s \mu + t \mu y') \, dx \, dy. \]

We can separate the integrals and use integration by parts to simplify this expression:

\[ \text{Cov}(X_s, X_t) = \int_{0}^t (\mu^2 + 2s \mu + t \mu y') \int_{0}^s (1 - \mu) \, dx \, dy. \]

\[ \text{Cov}(X_s, X_t) = \int_{0}^t (\mu^2 + 2s \mu + t \mu y') \, dx \, dy. \]

Since the integrand is an exponential function and the limits of integration are from 0 to \(t\), we have:

\[ \text{Cov}(X_s, X_t) = \int_{0}^t (1 - \mu)^{-1} (2s + t \mu y') \, dx. \]

This integral converges to zero as \(s\) approaches infinity if the mean of \(\frac{1}{(1 - \mu)^{-1}}\) is zero, which occurs when \(\int_{0}^t \frac{1}{(1 - \mu)^{-1}} = 1\). Therefore, if \(\text{Cov}(X_s, X_t) = \inf(s, t)\), then \(X_0 = 0\) implies that \((X_t)\) is a centered Gaussian process with mean \(\frac{1}{(1 - \mu)^{-1}}\).

In both cases, we have shown that if and only if \(X_0 = 0\) or \(\text{Cov}(X_s, X_t) = \inf(s, t)\), then \(X_0\) is a centered Gaussian process. Therefore, the correct answer to the problem is:

\[ \boxed{\text{Case 1: } (X_0 = 0) \quad \text{or} \quad \text{Cov}(X_s, X_t) = \inf(s, t)}. \]
