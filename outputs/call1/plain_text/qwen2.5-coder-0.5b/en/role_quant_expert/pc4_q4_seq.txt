Question 1:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau)$.

Answer:
Given the context of global and local stochastic calculus:

1. **Global Assumptions**:
   - \( W_t \) is a Brownian Motion, meaning that each step in the path of a random variable depends on the previous state and the current time.
   
2. **Local Assumptions**:
   - \( \tau \) is a bounded stopping time, which means that at any point after \( \tau \), the movement of the process is limited by this stopping time.

We need to compute \( \E(W_\tau) \), where \( W_\tau \) represents the value of the Brownian motion at time \( t = \tau \).

### Step-by-Step Solution

**Step 1: Analyze the Stopping Time Condition**

The stopping time condition states that at any point after \( \tau \), the movement of the process is limited by the bounded stopping time \( \tau \). This implies:
\[
W_\tau = W_0 + B(t, \tau)
\]
where \( W_0 \) is the initial value of the Brownian motion and \( B(t, \tau) \) is a random variable that depends on the Brownian motion at time \( t \).

### Step 2: Compute the Expected Value

The expected value \( \E(W_\tau) \) can be expressed in terms of \( W_0 \) and \( B(t, \tau) \). Using the property of expectation and the fact that \( W_t \) is a Brownian motion, we can use the following formula:

\[
E[W_\tau] = E[\sum_{i=1}^n W_i]
\]

To compute this sum, we need to consider the different ways in which the Brownian motion can be broken down into individual steps and summed.

**Step 3: Break Down the Brownian Motion**

We can break down the Brownian motion into two parts:
1. The first \( n \) steps are independent, so each step has an equal probability of occurring.
2. The last step is a jump, which is dependent on the previous step and the current time.

### Step 4: Calculate the Expected Value for Each Part

For each part, we can use the fact that the expected value of a sum of independent random variables is given by:

\[
E[\sum_{i=1}^n W_i] = \sum_{i=1}^n E[W_i]
\]

For the first \( n \) steps, the expected value \( E[\sum_{i=1}^n W_i] \) is simply the sum of the expected values:

\[
E[\sum_{i=1}^n W_i] = \sum_{i=1}^n \mathbb{E}[W_i]
\]

For the last step, \( E[W_\tau] \), which is a jump at time \( t \), has the following form:

\[
E[W_\tau] = B(t, \tau)
\]

Since \( B(t, \tau) \) is a random variable, its expected value is zero if it is independent of \( W_0 \). Therefore, we have:

\[
E[\sum_{i=1}^n W_i] = 0
\]

### Step 5: Sum the Expected Values

Thus, the total expected value \( E[W_\tau] \) is:

\[
E[W_\tau] = \sum_{i=1}^n \mathbb{E}[W_i] + E[B(t, \tau)] = 0
\]

### Step 6: Substitute the Given Values

Since \( W_0 \) is the initial value of the Brownian motion and \( B(t, \tau) \) is a random variable, we can substitute these values into our result:

\[
E[W_\tau] = \mathbb{E}[W_0 + B(t, \tau)] = 0
\]

Therefore, the expected value of \( W_\tau \) is:

\[
\boxed{\mathbb{E}[W_0 + B(t, \tau)]}
\]

Question 2:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau^2)$.

Answer:
The expected value of the square of a Brownian motion is given by:
\[
\mathbb{E}(W_t^2) = \mathbb{E}[(W_t + W_t)^2] = \mathbb{E}[W_t^2] + 2\mathbb{E}[W_t]W_t
\]
Since $W_t$ is a Brownian motion, we know that:
\[
W_t = \mu t + \sigma t^2
\]
Therefore,
\[
\mathbb{E}[W_t^2] = (\mu t + \sigma t^2)^2 = \mu^2 t^2 + 2\mu \sigma t^3 + t^4 = \mu^2 (t^2 + 2\mu \sigma t + 1)
\]
The expected value of a random variable is also given by:
\[
\mathbb{E}[W_t] = \int_{-\infty}^{\infty} W_t f(t) \, dt
\]
Since $W_t = \mu t + \sigma t^2$, we have:
\[
W_t f(t) = (\mu t + \sigma t^2) f(t)
\]
The expected value of the square of a Gaussian random variable is given by:
\[
\mathbb{E}[(W_t + W_t)^2] = \mathbb{E}[(\mu t + \sigma t^2) f(t)]^2 = (\mu^2 f(t))^2 + 2\mu \sigma f(t) \int_{-\infty}^{\infty} f(t) \, dt
\]
Since $f(t)$ is a constant (i.e., $\sigma f(t) = 0$), the expected value simplifies to:
\[
\mathbb{E}[(W_t + W_t)^2] = (\mu^2 f(t))^2
\]
Therefore,
\[
\mathbb{E}[W_\tau^2] = \mu^2 (t^2 + 2\mu \sigma t + 1)
\]

Thus, the expected value of $\E(W_\tau^2)$ is:
\[
\boxed{\mu^2 (t^2 + 2\mu \sigma t + 1)}
\]
