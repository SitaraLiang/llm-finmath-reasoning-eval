Question 1:
Show that a process $(X_t)_{t\in \R^+}$ is a Brownian motion if and only if: $X_0=0$, $(X_t)_{t\in \R^+}$ is a centered Gaussian process, ${\rm Cov}(X_s,X_t)=\inf(s,t).$

Answer:
The solution to the problem of proving that a process $\{X_t\}_{t\in \mathbb{R}^+\}$ is a Brownian motion if and only if $X_0=0$, $(X_t)_{t\in \mathbb{R}^+}$ is a centered Gaussian process, and ${\rm Cov}(X_s,X_t)=\inf(s,t)$ can be found using the properties of Brownian motions and covariance matrices.

1. **Statement 1**: A process $\{X_t\}_{t\in \mathbb{R}^+\}$ is a Brownian motion if and only if $X_0=0$.
2. **Proof**:
   - We start by noting that the Gaussian process $(X_t)_{t\in \mathbb{R}^+}$ has a common expectation, which can be expressed as $\mu_X = 0$. This means that for any point in time $t$, the average of the sequence $\{X_t\}_{t\in \mathbb{R}^+\}$ is zero.
   - We also know that $(X_t)_{t\in \mathbb{R}^+}$ is centered, meaning that there exists a mean $\mu$ and a standard deviation $\sigma$ such that $X_t = \mu + \sigma Z$, where $Z$ is a normal random variable. This can be written in the form $X_t = X_0 + \sigma T$, where $T$ is a time variable.
   - The covariance matrix of $(X_t)_{t\in \mathbb{R}^+}$, denoted as $\Sigma$, is given by:
     \[
     \Sigma = E[X_t X_t^T] = E[(\mu + \sigma Z)^2] = E[\mu^2 + 2 \mu \sigma Z + (\sigma Z)^2] = E[\mu^2 + 2 \mu \sigma Z + \sigma^2 Z^2] = E[\mu^2 + (3\sigma Z)^2]
     \]
   - Using the properties of expectation and covariance, we can further simplify the expression inside the expectation:
     \[
     \Sigma = E[\mu^2 + 9\sigma^2 Z^2]
     \]
     Since $\mu$ is the mean and $\sigma$ is the standard deviation, it follows that $E[\mu] = 0$ and $E[9\sigma^2 Z^2] = 9E[\sigma^2 Z^2]$.
   - Therefore, we have:
     \[
     \Sigma = E[\mu + 9\sigma^2 Z^2] = \mu + 9E[\sigma^2 Z^2]
     \]
   - If $X_0=0$, then $\mu_X = 0$. Substituting this into the equation, we get:
     \[
     0 + 9E[\sigma^2 Z^2] = 0
     \]
     Simplifying this equation, we find:
     \[
     9E[\sigma^2 Z^2] = 0
     \]
     Dividing both sides by 9, we get:
     \[
     E[\sigma^2 Z^2] = 0
     \]

3. **Statement 2**: A process $\{X_t\}_{t\in \mathbb{R}^+}$ is a centered Gaussian process if and only if ${\rm Cov}(X_s,X_t)=\inf(s,t)$.
4. **Proof**:
   - We have already shown that $E[\sigma^2 Z^2] = 0$ from Statement 1. This means that the covariance matrix $\Sigma$ is zero, which implies that the covariance function is constant for all $X_t$ and all time $t$.
   - In a centered Gaussian process, the covariance function must be a linear function of $Z$. Let's denote this linear function by:
     \[
     \gamma(s,z) = c e^{-(s^2 + z^2)/2}
     \]
   - For the covariance matrix $\Sigma$, we have:
     \[
     \Sigma = E[\gamma(s,z)^2] = E[c e^{-(s^2 + z^2)/2}] = c E[1] = c
     \]
     This shows that the covariance matrix is constant for all $X_t$ and all time $t$, which means that the covariance function is constant for all $X_t$ and all time $t$.
   - Therefore, we have:
     \[
     {\rm Cov}(X_s,X_t) = \gamma(s,z) = c e^{-(s^2 + z^2)/2}
     \]
     Since $\Sigma = 0$, this implies that the covariance function is constant for all $X_t$ and all time $t$.

In summary, a process $\{X_t\}_{t\in \mathbb{R}^+}$ is a Brownian motion if and only if $X_0=0$, $(X_t)_{t\in \mathbb{R}^+}$ is a centered Gaussian process, and ${\rm Cov}(X_s,X_t)=\inf(s,t)$.
