Question 1:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau)$.

Answer:
To solve this problem, we need to find the expected value of the brownian motion $W_t$, which is defined as:

\[ W_t = W_0 e^{t \beta} \]

where:
- $W_0$ is the initial value of the Brownian motion.
- $\beta$ is a parameter that determines the speed at which the random variables change, typically 1 for an exponential distribution.
- $e^{t \beta}$ represents the random variable representing the time elapsed from the start of the process to moment t.

Since we are given that $\tau$ is a bounded stopping time, it means there exists a finite interval $[0, \tau]$ on which the Brownian motion does not change. This implies that the value of $\beta$ must be such that:

\[ e^{t \beta} \leq W_0 e^{\tau \beta} \]

This can be simplified to:

\[ \beta \leq \frac{W_0}{e^{\tau}} \]

We want to compute the expected value of this expression over the interval $[0, \tau]$. This is equivalent to finding the integral of $\beta$ from 0 to $\tau$:

\[ E\left(\beta \right) = \int_{0}^{\tau} \beta \, dt \]

Using the fundamental theorem of integration for integrals, we get:

\[ E\left(\beta \right) = \left[ \frac{1}{2} \beta^2 \right]_0^{\tau} = \frac{1}{2} \left( \beta^2 - 0^2 \right) = \frac{1}{2} \beta^2 \]

Therefore, the expected value of $\E(W_\tau)$ is:

\[ E\left(\E(W_\tau)\right) = E\left(\beta^2\) \]

Since we already know from Question 1 that $E(W_0) = W_0$, it follows that:

\[ E\left(\beta^2\right) = E(W_0)^2 = W_0^2 \]

Thus, the expected value of $\E(W_\tau)$ is:

\[ \boxed{W_0^2} \]

Question 2:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau^2)$.

Answer:
To solve the problem of computing \(\E(W_{\tau}^2)\) given that \(W_t\) is a Brownian Motion and \(\tau\) is a bounded stopping time, we need to consider the properties of Brownian Motion and how they influence the expected value of their square.

1. **Understanding Brownian Motion:**
   - Brownian Motion (BM) is a continuous stochastic process defined by the following equation:
     \[
     dW_t = W_{t-1} + dB_t
     \]
   - The expectation of \(dW_t\) is zero because it is symmetric around zero:
     \[
     E(dW_t) = 0
     \]

2. **Expected Value of Square:**
   - We need to find the expected value of \(W_{\tau}^2\). Since \(W_t\) is a Brownian Motion, we can express \(W_{\tau}^2\) as:
     \[
     W_{\tau}^2 = (W_{\tau-1})^2 + 2W_{\tau-1}\frac{dW_{\tau-1}}{dt}
     \]
   - To find the expected value, we can use the property of Brownian Motion that states:
     \[
     E(W_t) = \mu t + \sigma W_t
     \]
   - Substituting this into the expression for \(W_{\tau}^2\), we get:
     \[
     W_{\tau}^2 = (\mu t + \sigma W_t)^2 + 2(\mu t + \sigma W_t)\frac{dW_{\tau-1}}{dt}
     \]
   - The second term inside the parentheses is the expectation of \(dW_{\tau-1}\):
     \[
     E(dW_{\tau-1}) = 0
     \]

3. **Substituting into the Expression for \(W_{\tau}^2\):**
   \[
   W_{\tau}^2 = (\mu t + \sigma W_t)^2 + 2(\mu t + \sigma W_t)(0)
   \]
   Simplifying, we get:
   \[
   W_{\tau}^2 = (\mu t + \sigma W_t)^2
   \]

4. **Conclusion:**
   - The expected value of \(W_{\tau}^2\) is simply \(\E(W_{\tau}^2)\), which is the same as \(W_{\tau}\):
     \[
     \E(W_{\tau}^2) = W_{\tau}
     \]

Therefore, the answer to Question 2 is:
\[
\boxed{W_\tau}
\]
