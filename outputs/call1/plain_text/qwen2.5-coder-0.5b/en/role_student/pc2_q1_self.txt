Question 1:
Show that a process $(X_t)_{t\in \R^+}$ is a Brownian motion if and only if: $X_0=0$, $(X_t)_{t\in \R^+}$ is a centered Gaussian process, ${\rm Cov}(X_s,X_t)=\inf(s,t).$

Answer:
To show that a process $\{X_t\}_{t \in \mathbb{R}^+\}$ is a Brownian motion if and only if $X_0 = 0$, $(X_t)_{t \in \mathbb{R}^+}$ is a centered Gaussian process, ${\rm Cov}(X_s, X_t) = \inf(s,t)$,

We start by recalling the definition of a Brownian motion. A random variable $\{Y_t\}_{t \in \mathbb{R}}$ is a Brownian motion if and only if it satisfies the following conditions:

1. $Y_0 = 0$
2. $E[Y^2] = 1$

We will use these conditions to prove our claim. Let's start with the first condition: $Y_0 = 0$. This means that the process $\{X_t\}_{t \in \mathbb{R}}$ starts at zero and has no jumps.

Next, we need to show that $(X_t)_{t \in \mathbb{R}^+}$ is a centered Gaussian process. A centered Gaussian process is defined as a random variable $Y_t$ such that:
1. $E[Y^2] = 1$
2. $\text{Var}(Y_t) = 0$

We can start by assuming that $(X_t)$ is a centered Gaussian process. Then, we have:
\[ E[X_t^2] = E[(X_{t-1})^2 + (X_t)^2] = E[X_{t-1}^2] + 2E[X_t]^2 = \text{Var}(X_t) + 2E[X_t^2] = 0 \]

This implies that:
\[ 0 = \text{Var}(X_t^2) \]
Since $\text{Var}(X_t^2)$ is always non-negative, it follows that $E[X_t^2] = 0$. Therefore, the process $(X_t)$ is centered Gaussian.

Now, let's consider the second condition: ${\rm Cov}(X_s, X_t) = \inf(s,t)$. We can use the fact that $\{X_t\}_{t \in \mathbb{R}}$ is a centered Gaussian process to show that:
\[ {\rm Cov}(X_s, X_t) = \text{Var}(X_s) + E[X_t^2] - E[X_s X_t] = 0 \]
This implies that:
\[ \text{Var}(X_s) = E[X_t^2] - E[X_s X_t] \]

Since $\text{Var}(X_s)$ is always non-negative and $E[X_s X_t]$ is a random variable such that $E[X_s X_t] = 0$, it follows that:
\[ E[X_s^2] - E[X_s X_t] = 0 \]
This implies that the process $(X_t)$ has a zero mean. Therefore, $(X_t)$ is a Brownian motion.

Thus, we have shown that a process $\{X_t\}_{t \in \mathbb{R}^+\}$ is a Brownian motion if and only if $X_0 = 0$, $(X_t)_{t \in \mathbb{R}^+}$ is a centered Gaussian process, and ${\rm Cov}(X_s, X_t) = \inf(s,t)$.

The answer to the question is:
