Question 1:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau)$.

Answer:
To solve this problem, we need to use the properties of brownian motion and local stopping times. Let's break it down step by step.

### Step-by-Step Solution

#### Brownian Motion (Brownian Motion)
The stochastic process \( W_t \) is defined as:
\[ W_t = W_{t-1} + B(t, W_{t-1}) \]
where \( B(t, W_{t-1}) \) is a standard normal random variable.

### Local Stopping Time
For a bounded stopping time \(\tau\), the expected value of \(W_\tau\) can be computed using the properties of Brownian motion. The key observation here is that:
\[ E(W_t - W_{\tau}) = E(B(t, W_{t-1})) \]
because the increments of the Brownian motion are independent.

### Applying to Our Problem

1. **Calculate \(E(B(t, W_{t-1}))\):**
   The standard normal random variable \(B(t, W_{t-1})\) is normally distributed with mean 0 and variance 1 (since \(W_{t-1}\) is a Brownian Motion). Therefore:
   \[ E(B(t, W_{t-1})) = N(0, 1) \]

2. **Compute the Expected Value of \(W_t - W_{\tau}\):**
   Since \(\tau\) is bounded, we can find the expected value of \(W_\tau - W_t\) by subtracting \(B(t, W_{t-1})\):
   \[ E(W_\tau - W_t) = E(B(t, W_{t-1})) - B(t, W_{t-1}) = N(0, 1) - N(0, 1) = 0 \]

3. **Use the Property of Brownian Motion:**
   By the property that \(E(W_\tau - W_t) = E(B(t, W_{t-1}))\), we have:
   \[ E(W_\tau) = N(0, 1) \]

### Conclusion
The expected value of \(W_\tau\) is:
\[ \boxed{N(0, 1)} \]

Question 2:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau^2)$.

Answer:
To find the expectation value of \( W_{\tau}^2 \), we need to understand the properties of Brownian Motion and the behavior of \( W_t \) when it satisfies a bounded stopping time condition.

### Step 1: Identify the Type of Process
We are dealing with a brownian motion, which means that the process is independent of time. The variance of a brownian motion is constant and does not depend on the amount of time over which it has been observed.

### Step 2: Consider the Bounded Stopping Time Condition
Given that \( \tau \) is a bounded stopping time, we know that if \( W_t < 0 \), then the process will eventually reach negative infinity. This means:
\[ W_{\tau}^2 = -W_{\tau-1}^2 \]

### Step 3: Use the Properties of Brownian Motion
Since \( W_t \) is independent and processes are identically distributed, the expectation value of \( W_{\tau-1}^2 \) can be expressed in terms of a standard normal distribution. This is because:
\[ E(W_{\tau-1}^2) = E(-W_{\tau-1}^2) \]
and
\[ E(-W_{\tau-1}^2) = \int_0^{\tau} (-W_t)^2 \, dt \]

### Step 4: Compute the Integral
We need to compute the integral:
\[ E(-W_{\tau-1}^2) = \int_0^{\tau} -W_t^2 \, dt \]
Using the substitution \( u = W_t \), we get:
\[ du = W_t \, dW_t = W_t \frac{d}{dt}(u) = W_t e^{-t} \]
Thus,
\[ E(-W_{\tau-1}^2) = -E(W_{\tau}) \int_0^{\tau} e^{-t} \, dt \]

### Step 5: Evaluate the Integral
The integral \(\int_0^{\tau} e^{-t} \, dt\) is a standard exponential integral. The value of this integral can be found using the substitution \( v = e^{-t} \), which gives:
\[ \int_0^{\tau} e^{-t} \, dt = \int_0^{\infty} v^2 \, dv = \left[ \frac{v^3}{3} \right]_0^{\infty} = \frac{1}{3} \]
Therefore,
\[ E(W_{\tau}) = -E(W_{\tau-1}) = -\frac{1}{3} \]

### Step 6: Compute the Expectation Value
Now, we substitute back into our expression for \( E(-W_{\tau-1}^2) \):
\[ E(-W_{\tau}) = -E(W_{\tau-1}) = -\frac{1}{3} \]
\[ E(W_\tau^2) = -E(W_{\tau}) = -\frac{1}{3} \]

### Final Answer
The expectation value of \( W_{\tau}^2 \) is:
\[ \boxed{-\frac{1}{3}} \]
