Question 1:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau)$.

Answer:
To solve this problem, we need to use the properties of Brownian Motion and the concept of stochastic differential equations (SDEs). Let's break it down step-by-step:

1. **Define the Brownian Motion:**
   The Brownian Motion is defined by its drift term \( \mathbf{dW_t} = \nu(t, W_t) dt + \sigma(t, W_t) dW_t \), where:
   - \( W_t \) is a standard normal random variable,
   - \( \nu(t, W_t) \) is the drift process (usually constant and independent),
   - \( \sigma(t, W_t) \) is the volatility process (usually constant and independent).

2. **Stochastic Differential Equation (SDE):**
   The SDE for a Brownian Motion with drift and volatility can be written as:
   \[
   dW_t = \nu(t, W_t) dt + \sigma(t, W_t) dW_t
   \]
   This is a first-order linear SDE. It is known that the solution to this equation depends on the initial condition \( W_0 \). If we assume that \( W_0 \) has mean 0 and variance 1 (which is a reasonable assumption for Brownian motion), then:
   \[
   dW_t = \nu(t, W_t) dt + \sigma(t, W_t) dW_t
   \]
   We can factor out the drift term \( \nu(t, W_t) \):
   \[
   dW_t = \nu(t)(1 + \sigma(t)) dt
   \]
   Let \( \rho(t) = \nu(t)(1 + \sigma(t)) \), then:
   \[
   dW_t = \rho(t) dt
   \]
   The solution to this equation is given by the solution to:
   \[
   W_t = W_0 e^{\int_{t}^T \rho(s) ds}
   \]

3. **Compute \( \E(W_\tau) \):**
   To find \( \E(W_\tau) \), we need to integrate the SDE from 0 to \( \tau \):
   \[
   E(W_\tau) = \int_{0}^{\tau} \rho(s) ds
   \]
   The expected value of a standard normal random variable \( W \) is 0. Therefore:
   \[
   E(W_0 e^{\int_{t}^T \rho(s) ds}) = \E(W_0 e^{\int_{0}^T \nu(t)(1 + \sigma(t)) dt}) = E(\nu(T) e^{\int_{0}^T 1 + \sigma(t)) dt)
   \]
   Since \( \rho(t) = \nu(t)(1 + \sigma(t)) \), we have:
   \[
   E(W_0 e^{\int_{0}^T 1 + \sigma(t)) dt) = E(\nu(T) \int_{0}^T 1 + \sigma(t)) dt
   \]
   Let \( u(t) = \int_{0}^t (1 + \sigma(t)) dt \). Then:
   \[
   E(W_0 e^{\int_{0}^T 1 + \sigma(t)) dt) = E(\nu(T) u)
   \]

4. **Use the Brownian Motion Properties:**
   By properties of Brownian motion, we know that \( \E(W_t) = W_0 \), where \( W_0 \) is a standard normal random variable. Therefore:
   \[
   E(W_0 e^{\int_{0}^T 1 + \sigma(t)) dt) = W_0 e^{\int_{0}^T (1 + \sigma(t)) dt} = W_0
   \]

Therefore, the expected value of \( W_\tau \) is:
\[
\boxed{W_0}
\]

Question 2:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau^2)$.

Answer:
To answer Question 2, we need to use the properties of Brownian Motion and the concept of conditional expectation. Let's start by recalling some fundamental properties of Brownian Motion:

1. **Brownian Motion Definition**: The $W_t$ process is a stochastic process defined on a finite interval $(0, T)$ with continuous paths, where $T > 0$. It satisfies the stochastic differential equation:
   \[
   dW_t = W_{t+1} - W_t
   \]
   Additionally, we have:
   \[
   \E(W_t) = W_0
   \]

2. **Conditional Expectation**:
   For any random variable $X$, the conditional expectation $\E(X \mid Y)$ is given by:
   \[
   \E(X \mid Y) = \frac{\E(X Y)}{\mathbb{E}(Y)}
   \]
   where $\mathbb{E}(Y)$ is the expected value of $Y$.

3. **Application to Brownian Motion**:
   For a Brownian motion $W_t$, the conditional expectation of $W_{t+1} \mid W_t = y$ can be written as:
   \[
   \E(W_{t+1} \mid W_t = y) = \frac{\mathbb{E}(W_{t+1} \cdot y)}{\mathbb{E}(y)}
   \]
   Using the definition of Brownian Motion, we know that $\mathbb{E}(W_{t+1} \cdot y) = W_{t+1} - W_t$ and $\mathbb{E}(y) = 0$. Therefore:
   \[
   \E(W_{t+1} \mid W_t = y) = W_{t+1}
   \]

4. **Conditional Expectation of $W_\tau^2$**:
   We need to find $\E(W_\tau^2)$ for a bounded stopping time $\tau$. Since $\tau$ is a stopping time, we can write:
   \[
   \E(W_{t+1}) = W_0
   \]
   Therefore:
   \[
   \E(W_{t+2}) = \mathbb{E}(W_t \cdot W_t) = \E(W_t^2)
   \]
   Using the property of Brownian Motion again, we know that $\E(W_t^2) = \mathbb{E}(W_t \cdot W_t)$ and $\mathbb{E}(t) = 0$. Therefore:
   \[
   \E(W_{t+2}) = \mathbb{E}(W_t^3)
   \]
   Using the same property, we know that $\E(W_t^3) = \mathbb{E}(W_t \cdot W_t)$ and $\mathbb{E}(u) = 0$. Therefore:
   \[
   \E(W_{t+2}) = \mathbb{E}(W_t^4)
   \]
   Continuing this process, we get:
   \[
   \E(W_\tau^3) = \mathbb{E}(W_t^5)
   \]

Therefore, the conditional expectation of $W_\tau^2$ for a bounded stopping time $\tau$ is:
\[
\boxed{\mathbb{E}(W_t^5)}
