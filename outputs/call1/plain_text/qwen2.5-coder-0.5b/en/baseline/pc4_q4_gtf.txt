The key insight is that the expected value of a Brownian motion starting at 0 is the same as the initial expected value, which in this case is \(\mu\). For Brownian Motion starting at 0, the state space has only one element, which corresponds to the zeroth state. Therefore, we have:
\[

\]

\]

### Question 1: Compute \(\E(W_\tau)\)

Given:
- $W_t$ is a Brownian Motion.
- $\tau$ is a bounded stopping time.

**Objective**: We need to find \(\E(W_\tau)\), the expected value of $W_t$ at time $\tau$.

### Arguments

1. **Martingale Property**: Since \(W_t\) is a Brownian Motion, it satisfies the property that \(W_t \geq 0\) for all $t \in \mathbb{R}$. This means that the expected value of \(W_t^2\) (where \(W_t = X_t - X_{t-1}\)) must be non-negative.

   \[
   E(W_t^2) = E(X_t^2 - X_{t-1}^2)
   \]

   \[
   X_t = W_t - X_{t-1} = (W_t^2 + W_{t-1}) / 2

   E(W_t^2) = E\left(\frac{(W_t^2 + W_{t-1})}{2}\right)

   Using the property of Brownian Motion again, we get:

4. **Substituting \(E(W_\tau)\)**: Since \(\E(W_\tau) > 0\) and \(\tau\) is bounded, we have:
   \[
