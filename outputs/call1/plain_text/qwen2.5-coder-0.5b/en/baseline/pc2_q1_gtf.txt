Question 1:

Answer:
To show that a process $(X_t)_{t\in \mathbb{R}^+$) is a Brownian motion if and only if $X_0 = 0$, $(X_t)_{t\in \mathbb{R}^+}$ is a centered Gaussian process, ${\rm Cov}(X_s, X_t) = \inf(s, t)$, we need to follow these steps:

### Step 1: Understanding Brownian Motion
A process $(X_t)$ is a Brownian motion if and only if it satisfies the following properties:
1. $X_0 = 0$ for all $t > 0$.
2. $\sqrt{2}\mathbf{i} \cdot X_t = \boldsymbol{\nu}$, where $\boldsymbol{\nu} = (\mu, \sigma^2)$ is a centered Gaussian process.

### Step 2: Understanding Centered Gaussian Process
A centered Gaussian process $(\mathbf{x}, \Sigma_x)$ satisfies the following properties:
1. $\mathbf{x}_0 = \mu$.
2. $\mathbf{x} \sim N(\mu, \Sigma_x^2)$ for all $x \in \mathbb{R}$.

### Step 3: Expressing Covariance in Terms of Centered Gaussian Process
The covariance between two centered Gaussian processes $(\mathbf{x}, \Sigma_x)$ and $(\mathbf{x'}, \Sigma_x')$ can be expressed as:
\[
\text{Cov}(\mathbf{x}, \mathbf{x'}) = (\sigma_x^2 + \Sigma_x'^2)^{-1} \Sigma_x \Sigma_x'
\]
where $\mathbf{x'} = \frac{\mathbf{x} - \mathbf{x}_0}{\sqrt{\Sigma_x'^2}}$.

### Step 4: Substituting the Properties
Substitute $X_0 = 0$, $\sigma_x^2 = 1$, and $\Sigma_x' = \frac{1}{2}\Sigma_x^2$ into the expression for covariance:
\[
\text{Cov}(\mathbf{x}, \mathbf{x'}) = \left(1 + \frac{1}{2}\right)^{-1} \cdot 1 \cdot \frac{1}{2}\Sigma_x^2 = \frac{3}{4}\Sigma_x^2
\]
This means that for a centered Gaussian process, the covariance between two random variables is always positive and equal to $\frac{3}{4}\sigma_x^2$.

### Step 5: Checking Conditions for Brownian Motion
Given that $X_0 = 0$, the properties of the centered Gaussian process imply:
1. The initial condition $X_0 = 0$ holds.
2. The covariance property is satisfied: $\sqrt{2}\mathbf{i} \cdot X_t = \boldsymbol{\nu}$, where $\boldsymbol{\nu} = (\mu, \sigma^2)$.

### Conclusion
By combining the properties of centered Gaussian processes and Brownian motion, we see that a process $(X_t)_{t\in \mathbb{R}^+}$ is a Brownian motion if and only if $X_0 = 0$, $(X_t)_{t\in \mathbb{R}^+}$ is a centered Gaussian process, and ${\rm Cov}(X_s, X_t) = \frac{3}{4}\sigma_x^2$.

Thus, the final answer to Question 1 is:
\[
\boxed{\text{A Brownian motion if and only if } X_0 = 0, (X_t)_{t\in \mathbb{R}^+} \text{ is a centered Gaussian process, and } \text{${\rm Cov}(X_s, X_t) = \frac{3}{4}\sigma_x^2}}
