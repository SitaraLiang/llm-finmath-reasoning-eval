A process \( (X_t)_{t \geq 0} \) is a Brownian motion if and only if it satisfies the following:

1. \( X_0 = 0 \),
2. It is a centered Gaussian process,
3. The covariance function is \( \text{Cov}(X_s, X_t) = \min(s, t) \).

**Proof:**

**(⇒)** Assume \( (X_t) \) is a Brownian motion.

- **Condition 1:** By definition, \( X_0 = 0 \).
  
- **Condition 2:** Each increment \( X_t - X_s \) for \( t > s \) is normally distributed with mean zero. Hence, the process is centered Gaussian.
  
- **Condition 3:** For Brownian motion, \( \text{Cov}(X_s, X_t) = \min(s, t) \).

**(⇐)** Assume conditions 1, 2, and 3 hold.

- The process starts at zero and has independent increments due to the covariance structure. Specifically, for any \( s < t \), \( \text{Cov}(X_t - X_s, X_s) = 0 \), implying independence.
  
- Since it is a Gaussian process with mean zero and independent increments, it is a Lévy process. The variance of each increment is equal to time, confirming it as Brownian motion.

Thus, the equivalence holds.

\boxed{X_t \text{ is a Brownian motion if and only if } X_0 = 0,\ (X_t) \text{ is centered Gaussian}, \text{and } \text{Cov}(X_s, X_t) = \min(s,t).}
