Question 1:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau)$.

Answer:
The expected value of \( W_\tau \) when \( \tau \) is a bounded stopping time can be computed using the Optional Stopping Theorem. Since Brownian motion \( W_t \) is a martingale and \( \tau \) is a bounded stopping time, we have:

\[
\E[W_\tau] = \E[W_0] = 0
\]

**Answer:**  
\boxed{0}

Question 2:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau^2)$.

Answer:
To compute \(\mathbb{E}[W_{\tau}^2]\) when \(\tau\) is a bounded stopping time, we utilize the fact that \(W_t^2 - t\) is a martingale. Applying the optional stopping theorem at the bounded stopping time \(\tau\), we have:

\[ \mathbb{E}[W_{\tau}^2 - \tau] = 0 \]

This implies:

\[ \mathbb{E}[W_{\tau}^2] = \mathbb{E}[\tau] \]

Thus, the expected value of \(W_{\tau}^2\) is equal to the expectation of \(\tau\).

Answer: \(\boxed{\mathbb{E}[\tau]}\)
