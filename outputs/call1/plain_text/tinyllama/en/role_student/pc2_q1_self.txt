Question 1:
Show that a process $(X_t)_{t\in \R^+}$ is a Brownian motion if and only if: $X_0=0$, $(X_t)_{t\in \R^+}$ is a centered Gaussian process, ${\rm Cov}(X_s,X_t)=\inf(s,t).$

Answer:
Proof:

Let us first assume that $(X_t)_{t\in \R^+}$ is a Brownian motion. Then, it satisfies the following conditions:

- $X_0=0$ and $\mathbb{E}[X_1] = 0$.
- For every $t\in\R^+$, $X_{t-s} = X_s + \int_{s}^{t}dW_r$ is a centered Gaussian process with covariance function $(s,t)$ and variance function $\sigma^2(s,t)$.

Therefore, the Gaussian assumption of Brownian motion implies that $X_0=0$, $(X_t)_{t\in \R^+}$ is a centered Gaussian process.

Now let us assume that $(X_t)_{t\in \R^+}$ is a centered Gaussian process with covariance function and variance function as before.

Let $a\geq 0$ be some positive constant, then:

$${\rm Cov}(X_s,X_t) = {\rm Cov}(X_{t-s},X_s) + \int_{s}^{t}dW_r^2 - \int_{s-a}^{t}dW_r^2$$

Using the Gaussian assumption on $(X_t)_{t\in \R^+}$, we have:

$${\rm Cov}(X_s,X_t) = \int_{s-a}^t dW_r^2 - a^2 \sigma^2(s,t)$$

Therefore, the covariance function is non-negative and positive semi-definite. We also have:

$${\rm Var}(X_t) = {\rm Cov}(X_0,X_t)^2 \geq a^2\sigma^2(0,t)$$

Hence, $(X_t)_{t\in \R^+}$ is a centered Gaussian process. This completes the proof of our first assumption.

Next, we assume that ${\rm Cov}(X_s,X_t)=\inf(s,t)$. Let us differentiate both sides:

$${\rm Cov}\left(\frac{X_{s}}{N_s}, \frac{X_{t-s}}{N_{t-s}}\right) = \int_{\R^+} \frac{(s,t)}{dW_r^2} - \sigma^2(s,t)$$

We can also write:

$${\rm Cov}\left(\frac{X_{s}}{N_s}, \frac{X_{t-s}}{N_{t-s}}\right) =  {\rm Cov}(X_{s},X_t)-{\rm Cov}(X_0,X_t)$$

Therefore, the covariance function is non-negative and positive semi-definite. We also have:

$${\rm Var}(X_t) = \int_\R dW_r^2 - a^2\sigma^2(s,t)$$

This completes our second assumption. Therefore, we can conclude that both assumptions of the question hold.

This completes the proof.
