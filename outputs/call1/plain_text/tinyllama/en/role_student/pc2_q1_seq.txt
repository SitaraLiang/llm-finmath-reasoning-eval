Question 1:
Show that a process $(X_t)_{t\in \R^+}$ is a Brownian motion if and only if: $X_0=0$, $(X_t)_{t\in \R^+}$ is a centered Gaussian process, ${\rm Cov}(X_s,X_t)=\inf(s,t).$

Answer:

Assuming $\mathcal{F}_0=\emptyset$, let $X=(X_t)_{t\geqslant0}$ be a centered Gaussian process with covariance function $g(s,t)=\inf(s,t)$ for $(s,t)\in\R^2$. Then $X$ is a Brownian motion if and only if $X_0=0$, $X_t=(X_{t\wedge \tau})_{\tau\in\mathcal{F}_1}$ is a centered Gaussian process with covariance function $g(s,\cdot)=\inf(\cdot,t)$ for $(s,t)\in\R^2$ and $\mathcal{F}_1$ is the sigma-algebra generated by $\tau$, i.e., $\sigma(\tau,\mathcal{F}_1)$.

Here's how to prove this:

Assuming that $X_0=0$, we have $X_t=(X_{t\wedge \tau})_{\tau\in\mathcal{F}_1}$ is a centered Gaussian process with covariance function $g(s,\cdot)=\inf(\cdot,t)$ for $(s,t)\in\R^2$.

Therefore, by defining $\mathcal{F}=\sigma(\tau,\mathcal{F}_1)$, we have: $X_0=0$, $X=(X_t)_{t\geqslant0}$ is a Brownian motion if and only if $(X_{t\wedge \tau})_{\tau\in\mathcal{F}}=X$ for each $\tau$. This means that the random variable $g(s,\cdot)$ has values in $[0,1]$ for all $s$, which implies that $X$ is a Brownian motion.

Therefore, $X$ is a Brownian motion if and only if $X_0=0$, $X_t=(X_{t\wedge \tau})_{\tau\in\mathcal{F}_1}$ is a centered Gaussian process with covariance function $g(s,\cdot)=\inf(\cdot,t)$ for $(s,t)\in\R^2$, and $\mathcal{F}=\sigma(\tau,\mathcal{F}_1)$.
