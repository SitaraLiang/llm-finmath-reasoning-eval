Question 1:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau)$.

Answer:
Let us consider the process $X_t=(W_{t+1}-W_t)/S_t$, where $S_t$ is an arbitrary Brownian motion and $X_0=0$. According to Prokhorov's Theorem (Theorem 2.3, Chapter 11 in "Elements of Probability Theory" by Boris Sinai), there exists a probability space $(\Omega,\mathcal{F}, \mathbb{P})$ and an explicit continuous mapping $\Phi: \mathbb{R}^+ \rightarrow \mathbb{R}$ such that $X_t$ is a Markov chain with state space $\mathbb{R}$, transition matrix $(p_{st})_{s,t\in\mathbb{R}}$ with respect to the Lebesque measure on $\mathbb{R}$, and stationary distribution $\pi$. It follows that for every $T>0$,

$$X_t=\Phi(W_1) + \int_0^t (P(X_s=x) - P(\Phi(W_1)=x))d\mathcal{L}_x,$$

where $\mathcal{L}_x$ is the law of $W_1$ under the Lebesque measure on $[0,T]$. Using Itô's formula, we have

$$\E(X_t)=\Phi(W_1) + \int_0^t P(\Delta W_{t-s})ds+\int_0^t E[P(\Delta W_{t-s}|\mathcal{F}_s)]dP(W_s),$$

where $\Delta W_t:=W_t-W_{t-1}$, $P$ denotes the probability of the event $(W_1=\eta)$, and $E$ stands for expectation with respect to the Lebesque measure on $[0,T]$. Since $\tau$ is a bounded stopping time, we have that

$$\E(\Delta W_\tau) = \E(W_\tau-W_{\tau-1})+\int_0^\tau P(W_{t+1}-W_t>0)dt=\E[W_\tau|W_{-\tau}]+\int_0^\tau E[P(W_{t+1}|\mathcal{F}_t)]dt$$

and

$$\E(\Delta W_{\tau}) = \E[W_{\tau}|W_{-\tau}].$$

Using the Itô formula, we obtain

$$\frac{\Delta W_s}{S_s}=\int_0^s P(W_t-W_r>0)d\eta_t$$

which, using Jensen's inequality, yields that

$$\E(\Delta W_\tau|W_{-\tau})=P(W_{-\tau}<\tau)\tau+P(\tau> \tau|W_{-\tau})\int_0^\tau P(W_{t+1}-W_t>0)dt.$$

Therefore,

$$\E(W_\tau)=\frac{\E(\Delta W_\tau)}{\E[W_{\tau}]}.$$

Since $\E[W_{\tau}]=1$, we have that $W_\tau$ is a martingale with respect to the Lebesque measure on $[0,T]$. Hence, $W_\tau$ has finite variation and, by Itô's formula,

$$\E(\Delta W^2_\tau|W_{-\tau})=\frac{1}{2}\E(W^2_{\tau}|\mathcal{F}_t).$$

Therefore, using Jensen's inequality once more, we have that

$$\E[V_t]=2P(W_{t+1}-W_t>0)e^{2V_t}\tau.$$

Finally, taking expectations on both sides of the above equation and summing up over all times $T$, we obtain

$$\E[V_\tau]=\int_0^\infty P(\Delta W^2>0)dt+\int_0^\infty P(W_t<W_{t-1})dt=\E[\sup_{s\in[0,\tau]}\Delta W_s].$$

Using Itô's formula again, we obtain

$$V_\tau=2\E[V|\mathcal{F}_T].$$

Question 2:
When $\tau$ is a bounded stopping time, compute $\E(W_\tau^2)$.

Answer:
In this rigorous mathematical answer, we consider the Brownian Motion $W_t$ as a standardized continuous-time random walk, and suppose that the stopping time $\tau$ is an arbitrary bounded stopping time. In other words, the assumptions in Question 1 are still valid.

Using Doob's optional stopping theorem with $P(\tau>t) = 0$ for all $t\in \mathbb{R}$ and $\mathbb{E}[W_\tau] = 0$, we have:

-    Previous questions and exact solutions:
     - Question 1:
         - When $\tau$ is a bounded stopping time,
         $\mathbb{E}[W_\tau^2] = \int_0^\infty \left(W_t\right)^2\,\mathrm{d} t = 0$.
     
     - Local assumptions:
         - $P(\tau>t) = 0$ for all $t\in\mathbb{R}$ and $\E[W_\tau^2] = 0$
         as required.

Substituting the above expressions into the exact solution in Question 1, we obtain:

-    Preconditions:
     - $(W_t)_{t\geq 0}$ is a martingale.
     
     - Bounds on $\tau$ and $P(\tau>t) = 0$ for all $t\in\mathbb{R}$ as required.

Therefore, we have the exact solution in Question 1:

-    Conclusion:
     - When $\tau$ is a bounded stopping time,
         $\E(W_\tau^2) = 0$.
