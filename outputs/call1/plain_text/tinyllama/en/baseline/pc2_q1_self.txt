Question 1:
Show that a process $(X_t)_{t\in \R^+}$ is a Brownian motion if and only if: $X_0=0$, $(X_t)_{t\in \R^+}$ is a centered Gaussian process, ${\rm Cov}(X_s,X_t)=\inf(s,t).$

Answer:
Proof:

1. If the process $(X_t)_{t\in \R^+}$ is a Brownian motion, then it is centered Gaussian with covariance function ${\rm Cov}(X_s,X_t)=\inf(s,t)$ for all $s,t\geqslant0$.

2. Conversely, suppose that $(X_t)_{t\in \R^+}$ is a centered Gaussian process, then it satisfies the covariance function ${\rm Cov}(X_s,X_t)=\inf(s,t)$ for all $s,t\geqslant0$.

3. To prove this, we use the fact that Gaussian processes with covariance function $\inf(s,t)$ are centered Gaussian, and we apply it to the process $(X_t)_{t\in \R^+}$. By definition of covariance function, there exists a random variable $W$ such that:
$${\rm Cov}(X_s,X_t)={\rm Cov}(\bar{W},\inf(s,t))$$
where:
$$\bar W := E[e_{t-\frac{1}{2}} X_{s} | \mathcal F_s] + E[\epsilon e_{t-\frac{1}{2}} | \mathcal F_s ]$$
is the expectation of $W$ given $(X_0, \dots, X_{s-1})$. Since $(X_t)_{t\in \R^+}$ is centered Gaussian with covariance function ${\rm Cov}(X_s,X_t)=\inf(s,t)$, we have that:
$${\rm Cov}(\bar W,\inf(s,t))=E[\epsilon e_{t-\frac{1}{2}}| \mathcal F_s] E[e_{t-\frac{1}{2}} | \mathcal F_s]=0$$
since $E[\epsilon e_{t-\frac{1}{2}}| \mathcal F_s]=0$ for all $t\geqslant0$. Therefore, $(X_t)_{t\in \R^+}$ is a centered Gaussian process.

4. The fact that the process satisfies the covariance function ${\rm Cov}(X_s,X_t)=\inf(s,t)$ for all $s,t\geqslant0$ follows from the definition of Gaussian processes with covariance function and using the law of total variance (Lemma 3.10 in [2]) on the mean process $(X_t)_{t\in \R^+}$.

5. Since $(X_t)_{t\in \R^+}$ is a centered Gaussian process, it follows that $h(X_s, X_t) = h(X_0, X_{s-1}) + h(X_{s}, X_{t})$ for all $s,t\geqslant0$. Since the process $(h(X_t)_{t\in \R^+})_{t\in \R^+}$ is centered Gaussian with covariance function ${\rm Cov}(h(X_s, X_t), h(X_r, X_v)) = \delta_{(s,t)}(\bar{W}_r-\bar{W}_s-\bar{W}_v)$ for all $s,t\geqslant0$, and $\delta$ is the Dirac delta function, we have that:
$${\rm Cov}(X_s, X_t) = {\rm Cov}(h(X_s,X_t), h(X_s,X_t))= \int_{\R^+} h(x,x) \, dx$$
for all $s,t\geqslant0$. Therefore:
$${\rm Var}(X_s) = {\rm Cov}(X_s, X_s) + \mathbb{V}(\bar{W}_s)$$
where $\mathbb{V}$ is the variance of a centered Gaussian process. Since $(X_t)_{t\in \R^+}$ satisfies the covariance function ${\rm Cov}(h(X_s,X_t), h(X_r, X_v)) = \delta_{(s,t)}(\bar{W}_r-\bar{W}_s-\bar{W}_v)$ for all $s,t\geqslant0$, we have that:
$${\rm Var}(X_s) + {\rm Cov}(\bar{W},\bar{W}) = {\rm Var}(h(X_s, X_s))$$
for all $s\in \R^+$. Therefore, $(X_t)_{t\in \R^+}$ satisfies the covariance function ${\rm Cov}(h(X_s,X_t), h(X_r, X_v)) = \delta_{(s,t)}(\bar{W}_r-\bar{W}_s-\bar{W}_v)$ for all $s,t\geqslant0$. Consequently, $(X_t)_{t\in \R^+}$ is a centered Gaussian process.

6. Finally, we prove that the process satisfies the covariance function ${\rm Cov}(h(X_s, X_t), h(X_r, X_v)) = \delta_{(s,t)}(\bar{W}_r-\bar{W}_s-\bar{W}_v)$ for all $s,t\geqslant0$. Using the law of total variance on the mean process $(X_t)_{t\in \R^+}$, we have:
$${\rm Cov}(h(X_s, X_t), h(X_r, X_v)) = {\rm Cov}(\bar{W}_r-\bar{W}_s-\bar{W}_v, h(X_0, X_{s-1}))$$
for all $s,t\geqslant0$. Since:
$${\rm Cov}(h(X_0, X_{s-1}), h(X_{s}, X_{t})) = \delta_{(s,t)}(\bar{W}_r-\bar{W}_s-\bar{W}_v)$$
for all $s,t\geqslant0$, we have that:
$${\rm Cov}(h(X_s, X_t), h(X_r, X_v)) = \delta_{(s,t)}(\bar{W}_r-\bar{W}_s-\bar{W}_v)$$
for all $s,t\geqslant0$. Consequently, $(h(X_t)_{t\in \R^+})_{t\in \R^+}$ is a centered Gaussian process.

Question 2:
Show that if $W_t$ is a Brownian motion, $ \{X_t=t\;W_{\frac 1t}, t>0, X_0=0 \}$ is a Brownian motion too.

Answer:
Proof:

1. If $W_t$ is a Brownian motion, then it satisfies the covariance function ${\rm Cov}(X_s, X_t)=\frac{1}{2} \bar{\sigma}^2(s,t)$ for all $s,t\geqslant0$.

Let $h(x,y) = x+y$ and $f(w,w')= w^2+w'^2$, where $w=\frac{1}{2} \bar{\sigma}(s,t) (\cdot)$ and $w'=\sqrt\frac{\bar{\sigma}^2}{2}(\cdot)$ for all $s,t\geqslant0$.

Since $h(x,y)= f(x+y,y)$, we have:
$${\rm Cov}(X_s, X_t) = {\rm Cov}(f(X_s, X_t), f(X_s, X_t)) = \int_{-\infty}^{\infty} x^2 \, dx + \int_{-\infty}^{\infty}\left(\frac{1}{2} \bar{\sigma}^2(s,t) + y^2\right)\, dy$$
for all $s,t\geqslant0$.

By integration by parts:
$${\rm Cov}(X_s, X_t) = {\rm Cov}\left(\int_{-\infty}^{\infty} x \, dx, \frac{1}{2} \bar{\sigma}^2(s,t)\right) + {\rm Cov}(\int_{-\infty}^{\infty}x^2\,dx,0)$$
$$= {\rm Cov}\left(X_s, \frac{1}{2} \bar{\sigma}^2(s,t)\right) + {\rm Var}(X_s)$$

where ${\rm Var}(X_s) = \int_{-\infty}^{\infty} x^4\, dx$ is the variance of $X_s$.

Therefore, $ \{X_t=t\;W_{\frac 1t}, t>0, X_0=0 \}$ is a Brownian motion too.

2. Using the same reasoning as in proof one, we have:
$${\rm Var}(h(X_s, X_t)) = {\rm Cov}(h(X_s, X_t), h(X_s, X_t)) - \frac{1}{4} \int_{-\infty}^{\infty} (x^2)^2 dx$$

Let $g(w,w')=w+w'$, we have:
$${\rm Var}(h(X_s, X_t)) = {\rm Cov}(\frac{1}{2} \bar{\sigma}^2(s,t), \frac{1}{2} \bar{\sigma}^2(s,t)) - \frac{1}{4} \int_{-\infty}^{\infty}\left((x+y)^3\right) dx dy$$

where $g(w,w') = (X_s, X_t) + w^2 + w'^2$.

Using the same integration by parts as in proof one, we have:
$${\rm Var}(h(X_s, X_t)) \leq {\rm Cov}^2(\frac{1}{2} \bar{\sigma}^2(s,t), \frac{1}{2} \bar{\sigma}^2(s,t)) - 4\int_{-\infty}^{\infty}\left((x+y)^3\right) dx dy$$

Since $h(\cdot)$ is a constant times a Gaussian random variable, we can apply Fubini's theorem:
$${\rm Var}(h(X_s, X_t)) \leq {\rm Cov}^2(X_s, X_t) - 4\int_{-\infty}^{\infty} (x^3)\, dx$$

where ${\rm Var}(X_s) = \int_{-\infty}^{\infty} x^4\, dx$ is the variance of $X_s$.

Therefore, $ \{X_t=t\;W_{\frac 1t}, t>0, X_0=0 \}$ is a Brownian motion too.

Conclusion:
$(h(X_t), h(X_t))$ and $(W_t, W_t)$ satisfy the covariances functions $\frac{1}{2} \bar{\sigma}^2$ and $ \bar{\sigma}^2/2$, respectively, provided that $W_t = (h(X_t), h(X_t))$.
